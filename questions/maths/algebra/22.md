## If the GCD of $x^2 - 2x - 24$ and $x^2 - kx - 6$ is $(x - 6)$, then the value of $k$ is

---

#### Since $(x - 6)$ is the GCD (a common factor) of both polynomials, $x = 6$ must be a root of both. Checking the first polynomial: $x^2 - 2x - 24 = (x - 6)(x + 4)$, confirming $(x-6)$ is indeed a factor.

For the second polynomial $x^2 - kx - 6$, since $(x - 6)$ is a factor, substituting $x = 6$ must make it zero:
$$6^2 - k(6) - 6 = 0$$
$$36 - 6k - 6 = 0$$
$$30 - 6k = 0$$
$$6k = 30$$
$$k = 5$$

**Verification:** With $k = 5$, the second polynomial is $x^2 - 5x - 6 = (x - 6)(x + 1)$, which indeed shares the factor $(x - 6)$ with the first polynomial.

**Answer:**
$$\mathbf{k = 5}$$
