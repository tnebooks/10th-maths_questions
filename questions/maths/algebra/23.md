## If $4x^4 - 24x^3 + 76x^2 + ax + b$ is a perfect square, then the values of $a$ and $b$ are

---

#### Since $4x^4 - 24x^3 + 76x^2 + ax + b$ is a perfect square of a quadratic expression, it must be of the form $(2x^2 + px + q)^2$, because the leading term $4x^4 = (2x^2)^2$.

Expanding $(2x^2 + px + q)^2$:
$$(2x^2 + px + q)^2 = 4x^4 + 4px^3 + (p^2 + 4q)x^2 + 2pqx + q^2$$

Comparing coefficients with $4x^4 - 24x^3 + 76x^2 + ax + b$:

**Coefficient of $x^3$:**
$$4p = -24 \implies p = -6$$

**Coefficient of $x^2$:**
$$p^2 + 4q = 76$$
$$(-6)^2 + 4q = 76$$
$$36 + 4q = 76$$
$$4q = 40$$
$$q = 10$$

**Coefficient of $x$ (this gives $a$):**
$$a = 2pq = 2(-6)(10) = -120$$

**Constant term (this gives $b$):**
$$b = q^2 = 10^2 = 100$$

**Verification:** $(2x^2 - 6x + 10)^2 = 4x^4 - 24x^3 + (36+40)x^2 - 120x + 100 = 4x^4 - 24x^3 + 76x^2 - 120x + 100$. This matches with $a = -120$, $b = 100$.

**Answer:**
$$\mathbf{a = -120, \ b = 100}$$
