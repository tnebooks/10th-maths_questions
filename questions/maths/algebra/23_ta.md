## $4x^4 - 24x^3 + 76x^2 + ax + b$ ஒரு முழு வர்க்கம் எனில், $a$ மற்றும் $b$-யின் மதிப்பு

---

#### $4x^4 - 24x^3 + 76x^2 + ax + b$ ஒரு இருபடிக் கோவையின் முழு வர்க்கமாக இருப்பதால், அது $(2x^2 + px + q)^2$ எனும் வடிவில் இருக்க வேண்டும், ஏனெனில் முதன்மைப் பதம் $4x^4 = (2x^2)^2$ ஆகும்.

$(2x^2 + px + q)^2$-ஐ விரிவாக்கினால்:
$$(2x^2 + px + q)^2 = 4x^4 + 4px^3 + (p^2 + 4q)x^2 + 2pqx + q^2$$

இதை $4x^4 - 24x^3 + 76x^2 + ax + b$ உடன் ஒப்பிடுக:

**$x^3$-இன் கெழு:**
$$4p = -24 \implies p = -6$$

**$x^2$-இன் கெழு:**
$$p^2 + 4q = 76$$
$$(-6)^2 + 4q = 76$$
$$36 + 4q = 76$$
$$4q = 40$$
$$q = 10$$

**$x$-இன் கெழு (இதுவே $a$):**
$$a = 2pq = 2(-6)(10) = -120$$

**மாறிலிப் பதம் (இதுவே $b$):**
$$b = q^2 = 10^2 = 100$$

**சரிபார்ப்பு:** $(2x^2 - 6x + 10)^2 = 4x^4 - 24x^3 + (36+40)x^2 - 120x + 100 = 4x^4 - 24x^3 + 76x^2 - 120x + 100$. இது $a = -120$, $b = 100$ என்பதை உறுதி செய்கிறது.

**விடை:**
$$\mathbf{a = -120, \ b = 100}$$
