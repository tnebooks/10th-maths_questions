## Find the sum to $n$ terms: $3 + 33 + 333 + \dots$ up to $n$ terms.

---

#### Each term of the series $3, 33, 333, \dots$ is a multiple of $3$ made up of repeated $1$'s:
$$3 = 3 \times 1, \quad 33 = 3 \times 11, \quad 333 = 3 \times 111, \quad \dots$$

So the sum can be written as:
$$S_n = 3(1 + 11 + 111 + \dots \text{to } n \text{ terms})$$

**Step 1: Rewrite each repunit using powers of 10.**

Multiply and divide the bracket by $9$:
$$S_n = \frac{3}{9}(9 + 99 + 999 + \dots \text{to } n \text{ terms}) = \frac{1}{3}(9 + 99 + 999 + \dots \text{to } n \text{ terms})$$

Each term inside is one less than a power of $10$:
$$9 = 10 - 1, \quad 99 = 100 - 1, \quad 999 = 1000 - 1, \quad \dots, \quad \underbrace{99\ldots9}_{n \text{ nines}} = 10^n - 1$$

**Step 2: Sum the rewritten series.**

$$S_n = \frac{1}{3}\Big[(10 - 1) + (10^2 - 1) + (10^3 - 1) + \dots + (10^n - 1)\Big]$$

$$S_n = \frac{1}{3}\Big[(10 + 10^2 + 10^3 + \dots + 10^n) - n\Big]$$

**Step 3: Evaluate the geometric series $10 + 10^2 + \dots + 10^n$.**

This is a GP with first term $a = 10$, common ratio $r = 10$, and $n$ terms. Using the GP sum formula $S = \dfrac{a(r^n - 1)}{r - 1}$:

$$10 + 10^2 + \dots + 10^n = \frac{10(10^n - 1)}{10 - 1} = \frac{10(10^n - 1)}{9}$$

**Step 4: Substitute back.**

$$S_n = \frac{1}{3}\left[\frac{10(10^n - 1)}{9} - n\right] = \frac{1}{3} \cdot \frac{10(10^n - 1) - 9n}{9}$$

$$S_n = \frac{10(10^n - 1) - 9n}{27}$$

**Check with $n = 3$:** $3 + 33 + 333 = 369$. Using the formula: $\dfrac{10(10^3 - 1) - 9(3)}{27} = \dfrac{10(999) - 27}{27} = \dfrac{9990 - 27}{27} = \dfrac{9963}{27} = 369$. ✓ Matches.

**Answer:**
$$\mathbf{S_n = \dfrac{10(10^n - 1) - 9n}{27}}$$
