## 3 + 33 + 333 + .... n உறுப்புகள் வரை கூடுதல் காண்க.

---

#### $3, 33, 333, \dots$ எனும் தொடரின் ஒவ்வொரு உறுப்பும் $1$-ன் மறுபடியும் மறுபடியும் தோன்றும் எண்களைக் கொண்ட $3$-ன் மடங்காக எழுதலாம்:
$$3 = 3 \times 1, \quad 33 = 3 \times 11, \quad 333 = 3 \times 111, \quad \dots$$

எனவே கூடுதலை பின்வருமாறு எழுதலாம்:
$$S_n = 3(1 + 11 + 111 + \dots \text{ } n \text{ உறுப்புகள் வரை})$$

**படி 1: ஒவ்வொரு உறுப்பையும் 10-ன் அடுக்குகள் கொண்டு மறுஎழுத்து செய்தல்.**

அடைப்புக்குறிக்குள் உள்ளதை $9$-ஆல் பெருக்கி வகுக்க:
$$S_n = \frac{3}{9}(9 + 99 + 999 + \dots \text{ } n \text{ உறுப்புகள் வரை}) = \frac{1}{3}(9 + 99 + 999 + \dots \text{ } n \text{ உறுப்புகள் வரை})$$

உள்ளே உள்ள ஒவ்வொரு உறுப்பும் 10-ன் அடுக்கிலிருந்து ஒன்று குறைவானது:
$$9 = 10 - 1, \quad 99 = 100 - 1, \quad 999 = 1000 - 1, \quad \dots, \quad \underbrace{99\ldots9}_{n \text{ ஒன்பதுகள்}} = 10^n - 1$$

**படி 2: மறுஎழுதப்பட்ட தொடரைக் கூட்டுதல்.**

$$S_n = \frac{1}{3}\Big[(10 - 1) + (10^2 - 1) + (10^3 - 1) + \dots + (10^n - 1)\Big]$$

$$S_n = \frac{1}{3}\Big[(10 + 10^2 + 10^3 + \dots + 10^n) - n\Big]$$

**படி 3: $10 + 10^2 + \dots + 10^n$ எனும் தொடர் வண்ண வடிவ (GP) தொடராக மதிப்பிடுதல்.**

இது முதல் உறுப்பு $a = 10$, பொது விகிதம் $r = 10$, $n$ உறுப்புகள் கொண்ட தொடர் வண்ண வடிவம். தொடர் வண்ண வடிவக் கூட்டல் சூத்திரம் $S = \dfrac{a(r^n - 1)}{r - 1}$-ஐப் பயன்படுத்த:

$$10 + 10^2 + \dots + 10^n = \frac{10(10^n - 1)}{10 - 1} = \frac{10(10^n - 1)}{9}$$

**படி 4: மீண்டும் பிரதியிடுதல்.**

$$S_n = \frac{1}{3}\left[\frac{10(10^n - 1)}{9} - n\right] = \frac{1}{3} \cdot \frac{10(10^n - 1) - 9n}{9}$$

$$S_n = \frac{10(10^n - 1) - 9n}{27}$$

**சரிபார்ப்பு $n = 3$:** $3 + 33 + 333 = 369$. சூத்திரத்தின்படி: $\dfrac{10(10^3 - 1) - 9(3)}{27} = \dfrac{10(999) - 27}{27} = \dfrac{9990 - 27}{27} = \dfrac{9963}{27} = 369$. ✓ பொருந்துகிறது.

**விடை:**
$$\mathbf{S_n = \dfrac{10(10^n - 1) - 9n}{27}}$$
