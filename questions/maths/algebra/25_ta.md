## வகுத்தல் படிமுறையைப் பயன்படுத்தி $64x^4 - 16x^3 + 17x^2 - 2x + 1$ என்பதின் வர்க்கமூலம் காண்க.

---

#### பல்லுறுப்புக்கோவையின் வர்க்கமூலம் காணும் நீள்வகுத்தல் முறையைப் பயன்படுத்துவோம் ($x$-இன் இறங்குவரிசை அடுக்குகளில் பதங்களை அமைத்தல்):

**படி 1:** முதல் பதம் $64x^4$. இதன் வர்க்கமூலம் $8x^2$ ($(8x^2)^2 = 64x^4$ என்பதால்). ஈவின் முதல் பதமாக $8x^2$-ஐ எடுத்துக்கொள்க.

$(8x^2)^2 = 64x^4$-ஐ வகுக்கப்படும் கோவையிலிருந்து கழிக்க:
$$64x^4 - 16x^3 + 17x^2 - 2x + 1 - 64x^4 = -16x^3 + 17x^2 - 2x + 1$$

**படி 2:** இதுவரை பெற்ற ஈவை இருமடங்காக்குக: $2(8x^2) = 16x^2$. இதுவே சோதனை வகுத்தி.

புதிய மீதியின் முதல் பதமான $-16x^3$-ஐ $16x^2$-ஆல் வகுக்க: $\dfrac{-16x^3}{16x^2} = -x$. $-x$-ஐ அடுத்த ஈவுப் பதமாக எடுத்துக்கொள்க.

புதிய வகுத்தி: $(16x^2 - x)$. இதை $-x$-ஆல் பெருக்க:
$$(16x^2 - x)(-x) = -16x^3 + x^2$$

இதை $-16x^3 + 17x^2 - 2x + 1$-இலிருந்து கழிக்க:
$$(-16x^3 + 17x^2 - 2x + 1) - (-16x^3 + x^2) = 16x^2 - 2x + 1$$

**படி 3:** இதுவரை பெற்ற ஈவான $8x^2 - x$-ஐ இருமடங்காக்குக: $2(8x^2 - x) = 16x^2 - 2x$. இதுவே புதிய சோதனை வகுத்தி.

மீதியின் முதல் பதமான $16x^2$-ஐ $16x^2$-ஆல் வகுக்க: $\dfrac{16x^2}{16x^2} = 1$. $+1$-ஐ அடுத்த ஈவுப் பதமாக எடுத்துக்கொள்க.

புதிய வகுத்தி: $(16x^2 - 2x + 1)$. இதை $1$-ஆல் பெருக்க:
$$(16x^2 - 2x + 1)(1) = 16x^2 - 2x + 1$$

இதை $16x^2 - 2x + 1$-இலிருந்து கழிக்க:
$$(16x^2 - 2x + 1) - (16x^2 - 2x + 1) = 0$$

மீதி $0$ ஆக இருப்பதால், வகுத்தல் முழுமையாக முடிவடைகிறது; இது கொடுக்கப்பட்ட கோவை ஒரு முழு வர்க்கம் என்பதை உறுதி செய்கிறது.

**ஈவு (வர்க்கமூலம்):**
$$8x^2 - x + 1$$

**சரிபார்ப்பு:** ஈவை வர்க்கமாக்க:
$$(8x^2 - x + 1)^2 = 64x^4 - 16x^3 + 17x^2 - 2x + 1$$

இது கொடுக்கப்பட்ட பல்லுறுப்புக்கோவையுடன் சரியாகப் பொருந்துகிறது. வர்க்கமூலம் எப்போதும் எதிர்மறை அல்லாத மதிப்பாக இருக்க வேண்டும் என்பதால், மட்டு (modulus) குறியீட்டுடன் விடையை எழுதுகிறோம்:

**விடை:**
$$\mathbf{\sqrt{64x^4 - 16x^3 + 17x^2 - 2x + 1} = |8x^2 - x + 1|}$$
