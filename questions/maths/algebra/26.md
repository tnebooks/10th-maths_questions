## Simplify: $\dfrac{1}{x^2 - 5x + 6} + \dfrac{1}{x^2 - 3x + 2} - \dfrac{1}{x^2 - 8x + 15}$

---

#### **Step 1: Factorize each denominator.**

$$x^2 - 5x + 6 = (x - 2)(x - 3)$$
$$x^2 - 3x + 2 = (x - 1)(x - 2)$$
$$x^2 - 8x + 15 = (x - 3)(x - 5)$$

So the expression becomes:
$$\frac{1}{(x-2)(x-3)} + \frac{1}{(x-1)(x-2)} - \frac{1}{(x-3)(x-5)}$$

**Step 2: Find the LCM of the denominators.**

The distinct linear factors across all three denominators are $(x-1), (x-2), (x-3), (x-5)$, each appearing at most once. So:
$$\text{LCM} = (x-1)(x-2)(x-3)(x-5)$$

**Step 3: Express each fraction with the LCM as denominator and combine.**

$$\frac{1}{(x-2)(x-3)} = \frac{(x-1)(x-5)}{(x-1)(x-2)(x-3)(x-5)}$$
$$\frac{1}{(x-1)(x-2)} = \frac{(x-3)(x-5)}{(x-1)(x-2)(x-3)(x-5)}$$
$$\frac{1}{(x-3)(x-5)} = \frac{(x-1)(x-2)}{(x-1)(x-2)(x-3)(x-5)}$$

So the combined expression is:
$$\frac{(x-1)(x-5) + (x-3)(x-5) - (x-1)(x-2)}{(x-1)(x-2)(x-3)(x-5)}$$

**Step 4: Expand each term in the numerator.**

$$(x-1)(x-5) = x^2 - 6x + 5$$
$$(x-3)(x-5) = x^2 - 8x + 15$$
$$(x-1)(x-2) = x^2 - 3x + 2$$

**Step 5: Combine the numerator.**

$$\text{Numerator} = (x^2 - 6x + 5) + (x^2 - 8x + 15) - (x^2 - 3x + 2)$$

$$= x^2 - 6x + 5 + x^2 - 8x + 15 - x^2 + 3x - 2$$

$$= (x^2 + x^2 - x^2) + (-6x - 8x + 3x) + (5 + 15 - 2)$$

$$= x^2 - 11x + 18$$

**Step 6: Factorize the numerator.**

$$x^2 - 11x + 18 = (x - 2)(x - 9)$$

(Check: $-2 \times -9 = 18$ and $-2 + -9 = -11$. ✓)

**Step 7: Simplify by cancelling the common factor $(x-2)$.**

$$\frac{(x-2)(x-9)}{(x-1)(x-2)(x-3)(x-5)} = \frac{x-9}{(x-1)(x-3)(x-5)}, \quad x \neq 1, 2, 3, 5$$

**Verification (numeric check at $x = 10$):** Original expression $= \dfrac{1}{(8)(7)} + \dfrac{1}{(9)(8)} - \dfrac{1}{(7)(5)} = \dfrac{1}{56} + \dfrac{1}{72} - \dfrac{1}{35} = \dfrac{1813}{477555}$. Simplified form $= \dfrac{10-9}{(9)(7)(5)} = \dfrac{1}{315} = \dfrac{1813}{477555}$. ✓ Both match.

**Answer:**
$$\mathbf{\dfrac{x - 9}{(x-1)(x-3)(x-5)}}$$
