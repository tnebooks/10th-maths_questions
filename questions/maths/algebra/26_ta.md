## சுருக்குக: $\dfrac{1}{x^2 - 5x + 6} + \dfrac{1}{x^2 - 3x + 2} - \dfrac{1}{x^2 - 8x + 15}$

---

#### **படி 1: ஒவ்வொரு வகுத்தியையும் காரணிப்படுத்துக.**

$$x^2 - 5x + 6 = (x - 2)(x - 3)$$
$$x^2 - 3x + 2 = (x - 1)(x - 2)$$
$$x^2 - 8x + 15 = (x - 3)(x - 5)$$

எனவே கோவை பின்வருமாறு ஆகும்:
$$\frac{1}{(x-2)(x-3)} + \frac{1}{(x-1)(x-2)} - \frac{1}{(x-3)(x-5)}$$

**படி 2: வகுத்திகளின் மீ.சி.ம காண்க.**

மூன்று வகுத்திகளிலும் தோன்றும் தனித்தனி நேரிய காரணிகள் $(x-1), (x-2), (x-3), (x-5)$ — ஒவ்வொன்றும் அதிகபட்சம் ஒரு முறை தோன்றுகிறது. எனவே:
$$\text{மீ.சி.ம} = (x-1)(x-2)(x-3)(x-5)$$

**படி 3: ஒவ்வொரு பின்னத்தையும் மீ.சி.ம-ஐ வகுத்தியாகக் கொண்டு எழுதி இணைக்க.**

$$\frac{1}{(x-2)(x-3)} = \frac{(x-1)(x-5)}{(x-1)(x-2)(x-3)(x-5)}$$
$$\frac{1}{(x-1)(x-2)} = \frac{(x-3)(x-5)}{(x-1)(x-2)(x-3)(x-5)}$$
$$\frac{1}{(x-3)(x-5)} = \frac{(x-1)(x-2)}{(x-1)(x-2)(x-3)(x-5)}$$

எனவே இணைந்த கோவை:
$$\frac{(x-1)(x-5) + (x-3)(x-5) - (x-1)(x-2)}{(x-1)(x-2)(x-3)(x-5)}$$

**படி 4: தொகுதியின் ஒவ்வொரு பதத்தையும் விரிவாக்குக.**

$$(x-1)(x-5) = x^2 - 6x + 5$$
$$(x-3)(x-5) = x^2 - 8x + 15$$
$$(x-1)(x-2) = x^2 - 3x + 2$$

**படி 5: தொகுதியை இணைக்க.**

$$\text{தொகுதி} = (x^2 - 6x + 5) + (x^2 - 8x + 15) - (x^2 - 3x + 2)$$

$$= x^2 - 6x + 5 + x^2 - 8x + 15 - x^2 + 3x - 2$$

$$= (x^2 + x^2 - x^2) + (-6x - 8x + 3x) + (5 + 15 - 2)$$

$$= x^2 - 11x + 18$$

**படி 6: தொகுதியைக் காரணிப்படுத்துக.**

$$x^2 - 11x + 18 = (x - 2)(x - 9)$$

(சரிபார்ப்பு: $-2 \times -9 = 18$ மற்றும் $-2 + -9 = -11$. ✓)

**படி 7: பொதுவான காரணி $(x-2)$-ஐ நீக்கி சுருக்குக.**

$$\frac{(x-2)(x-9)}{(x-1)(x-2)(x-3)(x-5)} = \frac{x-9}{(x-1)(x-3)(x-5)}, \quad x \neq 1, 2, 3, 5$$

**சரிபார்ப்பு ($x = 10$ எனும் எண் மதிப்பில்):** மூலக்கோவை $= \dfrac{1}{(8)(7)} + \dfrac{1}{(9)(8)} - \dfrac{1}{(7)(5)} = \dfrac{1}{56} + \dfrac{1}{72} - \dfrac{1}{35} = \dfrac{1813}{477555}$. சுருக்கப்பட்ட வடிவம் $= \dfrac{10-9}{(9)(7)(5)} = \dfrac{1}{315} = \dfrac{1813}{477555}$. ✓ இரண்டும் பொருந்துகின்றன.

**விடை:**
$$\mathbf{\dfrac{x - 9}{(x-1)(x-3)(x-5)}}$$
