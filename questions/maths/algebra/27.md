## Using the division method, find the GCD of $2x^4 + 13x^3 + 27x^2 + 23x + 7$, $x^3 + 3x^2 + 3x + 1$, and $x^2 + 2x + 1$.

---

#### To find the GCD of three polynomials by the division method, we first find the GCD of any two of them, then find the GCD of that result with the third polynomial (Euclid's division algorithm extended to three polynomials: $\gcd(a, b, c) = \gcd(\gcd(a, b), c)$).

**Step 1: Find GCD of $p_1 = x^2 + 2x + 1$ and $p_2 = x^3 + 3x^2 + 3x + 1$ by division.**

Divide $p_2$ by $p_1$:
$$x^3 + 3x^2 + 3x + 1 \div (x^2 + 2x + 1)$$

- $x^3 \div x^2 = x$. Multiply: $x(x^2 + 2x + 1) = x^3 + 2x^2 + x$.
  Subtract: $(x^3 + 3x^2 + 3x + 1) - (x^3 + 2x^2 + x) = x^2 + 2x + 1$.
- Bring down; divide $x^2$ by $x^2$: quotient term $+1$. Multiply: $1(x^2 + 2x + 1) = x^2 + 2x + 1$.
  Subtract: $(x^2 + 2x + 1) - (x^2 + 2x + 1) = 0$.

The remainder is $0$, so $p_1 = (x^2 + 2x + 1)$ divides $p_2$ exactly, meaning:
$$\gcd(p_1, p_2) = p_1 = x^2 + 2x + 1$$

**Step 2: Find GCD of $x^2 + 2x + 1$ and $p_3 = 2x^4 + 13x^3 + 27x^2 + 23x + 7$ by division.**

Divide $p_3$ by $(x^2 + 2x + 1)$:
$$2x^4 + 13x^3 + 27x^2 + 23x + 7 \div (x^2 + 2x + 1)$$

- $2x^4 \div x^2 = 2x^2$. Multiply: $2x^2(x^2 + 2x + 1) = 2x^4 + 4x^3 + 2x^2$.
  Subtract: $(2x^4 + 13x^3 + 27x^2 + 23x + 7) - (2x^4 + 4x^3 + 2x^2) = 9x^3 + 25x^2 + 23x + 7$.
- $9x^3 \div x^2 = 9x$. Multiply: $9x(x^2 + 2x + 1) = 9x^3 + 18x^2 + 9x$.
  Subtract: $(9x^3 + 25x^2 + 23x + 7) - (9x^3 + 18x^2 + 9x) = 7x^2 + 14x + 7$.
- $7x^2 \div x^2 = 7$. Multiply: $7(x^2 + 2x + 1) = 7x^2 + 14x + 7$.
  Subtract: $(7x^2 + 14x + 7) - (7x^2 + 14x + 7) = 0$.

The remainder is $0$ again, so $(x^2 + 2x + 1)$ divides $p_3$ exactly as well, with quotient $2x^2 + 9x + 7$:
$$p_3 = (x^2 + 2x + 1)(2x^2 + 9x + 7)$$

**Step 3: Conclusion.**

Since $(x^2 + 2x + 1)$ divides all three polynomials exactly (remainder $0$ in both divisions), and it is the GCD obtained from the first pair, it is the GCD of all three:
$$\gcd(p_1, p_2, p_3) = x^2 + 2x + 1 = (x + 1)^2$$

**Verification by factorization (cross-check using a second method):**
$$p_1 = x^2 + 2x + 1 = (x+1)^2$$
$$p_2 = x^3 + 3x^2 + 3x + 1 = (x+1)^3 \quad \text{(binomial expansion of } (x+1)^3\text{)}$$
$$p_3 = 2x^4 + 13x^3 + 27x^2 + 23x + 7$$

For $p_3$: testing $x = -1$: $2(1) + 13(-1) + 27(1) + 23(-1) + 7 = 2 - 13 + 27 - 23 + 7 = 0$, so $(x+1)$ is a factor. Dividing $p_3$ by $(x+1)$ twice (synthetic division) gives $p_3 = (x+1)^3(2x + 7)$.

So: $p_1 = (x+1)^2$, $p_2 = (x+1)^3$, $p_3 = (x+1)^3(2x+7)$.

The common factor with the **lowest power** across all three is $(x+1)^2$, confirming:
$$\mathbf{\gcd(p_1, p_2, p_3) = (x+1)^2}$$

**Answer:**
$$\mathbf{(x + 1)^2}$$
