## வகுத்தல் படிமுறையைப் பயன்படுத்தி $2x^4 + 13x^3 + 27x^2 + 23x + 7$, $x^3 + 3x^2 + 3x + 1$, $x^2 + 2x + 1$ ஆகியவற்றின் மீ.பொ.வ. காண்க.

---

#### மூன்று பல்லுறுப்புக்கோவைகளின் மீ.பொ.வ.-ஐ வகுத்தல் முறையில் காண, முதலில் எவையேனும் இரண்டின் மீ.பொ.வ.-ஐக் காண்போம், பின்னர் அந்த விடையின் மீ.பொ.வ.-ஐ மூன்றாவது பல்லுறுப்புக்கோவையுடன் காண்போம் (யூக்லிடின் வகுத்தல் படிமுறை மூன்று பல்லுறுப்புக்கோவைகளுக்கு விரிவாக்கப்பட்டது: $\gcd(a, b, c) = \gcd(\gcd(a, b), c)$).

**படி 1: $p_1 = x^2 + 2x + 1$ மற்றும் $p_2 = x^3 + 3x^2 + 3x + 1$ ஆகியவற்றின் மீ.பொ.வ.-ஐ வகுத்தல் மூலம் காணுதல்.**

$p_2$-ஐ $p_1$-ஆல் வகுக்க:
$$x^3 + 3x^2 + 3x + 1 \div (x^2 + 2x + 1)$$

- $x^3 \div x^2 = x$. பெருக்குக: $x(x^2 + 2x + 1) = x^3 + 2x^2 + x$.
  கழிக்க: $(x^3 + 3x^2 + 3x + 1) - (x^3 + 2x^2 + x) = x^2 + 2x + 1$.
- கீழே கொண்டு வந்து; $x^2$-ஐ $x^2$-ஆல் வகுக்க: ஈவுப் பதம் $+1$. பெருக்குக: $1(x^2 + 2x + 1) = x^2 + 2x + 1$.
  கழிக்க: $(x^2 + 2x + 1) - (x^2 + 2x + 1) = 0$.

மீதி $0$ ஆக இருப்பதால், $p_1 = (x^2 + 2x + 1)$ என்பது $p_2$-ஐ முழுமையாக வகுக்கிறது, அதாவது:
$$\gcd(p_1, p_2) = p_1 = x^2 + 2x + 1$$

**படி 2: $x^2 + 2x + 1$ மற்றும் $p_3 = 2x^4 + 13x^3 + 27x^2 + 23x + 7$ ஆகியவற்றின் மீ.பொ.வ.-ஐ வகுத்தல் மூலம் காணுதல்.**

$p_3$-ஐ $(x^2 + 2x + 1)$-ஆல் வகுக்க:
$$2x^4 + 13x^3 + 27x^2 + 23x + 7 \div (x^2 + 2x + 1)$$

- $2x^4 \div x^2 = 2x^2$. பெருக்குக: $2x^2(x^2 + 2x + 1) = 2x^4 + 4x^3 + 2x^2$.
  கழிக்க: $(2x^4 + 13x^3 + 27x^2 + 23x + 7) - (2x^4 + 4x^3 + 2x^2) = 9x^3 + 25x^2 + 23x + 7$.
- $9x^3 \div x^2 = 9x$. பெருக்குக: $9x(x^2 + 2x + 1) = 9x^3 + 18x^2 + 9x$.
  கழிக்க: $(9x^3 + 25x^2 + 23x + 7) - (9x^3 + 18x^2 + 9x) = 7x^2 + 14x + 7$.
- $7x^2 \div x^2 = 7$. பெருக்குக: $7(x^2 + 2x + 1) = 7x^2 + 14x + 7$.
  கழிக்க: $(7x^2 + 14x + 7) - (7x^2 + 14x + 7) = 0$.

மீதி மீண்டும் $0$ ஆக இருப்பதால், $(x^2 + 2x + 1)$ என்பது $p_3$-ஐயும் முழுமையாக வகுக்கிறது, ஈவு $2x^2 + 9x + 7$:
$$p_3 = (x^2 + 2x + 1)(2x^2 + 9x + 7)$$

**படி 3: முடிவு.**

$(x^2 + 2x + 1)$ என்பது மூன்று பல்லுறுப்புக்கோவைகளையும் முழுமையாக வகுப்பதால் (இரண்டு வகுத்தல்களிலும் மீதி $0$), மற்றும் இது முதல் இரண்டின் மீ.பொ.வ.-ஆக பெறப்பட்டதால், இதுவே மூன்றின் மீ.பொ.வ. ஆகும்:
$$\gcd(p_1, p_2, p_3) = x^2 + 2x + 1 = (x + 1)^2$$

**காரணிப்படுத்தல் மூலம் சரிபார்ப்பு (இரண்டாவது முறையைப் பயன்படுத்தி ஒப்பீடு):**
$$p_1 = x^2 + 2x + 1 = (x+1)^2$$
$$p_2 = x^3 + 3x^2 + 3x + 1 = (x+1)^3 \quad \text{(}(x+1)^3\text{-இன் இருசொல் விரிவாக்கம்)}$$
$$p_3 = 2x^4 + 13x^3 + 27x^2 + 23x + 7$$

$p_3$-க்கு: $x = -1$ எனப் பிரதியிட: $2(1) + 13(-1) + 27(1) + 23(-1) + 7 = 2 - 13 + 27 - 23 + 7 = 0$, எனவே $(x+1)$ ஒரு காரணி. $p_3$-ஐ $(x+1)$-ஆல் இரு முறை வகுக்க (தொகுத்தல் வகுத்தல்): $p_3 = (x+1)^3(2x + 7)$.

எனவே: $p_1 = (x+1)^2$, $p_2 = (x+1)^3$, $p_3 = (x+1)^3(2x+7)$.

மூன்றிலும் **குறைந்த அடுக்குடன்** தோன்றும் பொதுவான காரணி $(x+1)^2$ ஆகும், இது உறுதி செய்கிறது:
$$\mathbf{\gcd(p_1, p_2, p_3) = (x+1)^2}$$

**விடை:**
$$\mathbf{(x + 1)^2}$$
