## Find the sum to $n$ terms of the series $3 + 33 + 333 + \ldots$

---

#### The given series is $3 + 33 + 333 + \ldots$ up to $n$ terms. Each term is not in arithmetic or geometric progression directly, but each term can be rewritten as $3$ times a string of $1$'s: $3 = 3(1)$, $33 = 3(11)$, $333 = 3(111)$, and so on. So the sum is:
$$S_n = 3(1 + 11 + 111 + \ldots \text{to } n \text{ terms})$$

**Step 1: Rewrite each term using powers of 10.**

Each term inside the bracket can be written as a sum of powers of $10$ divided by $9$, since multiplying by $9$ turns a string of $1$'s into $10^k - 1$:
$$1 = \frac{10 - 1}{9}, \quad 11 = \frac{100 - 1}{9}, \quad 111 = \frac{1000 - 1}{9}, \ \ldots$$

In general, the $k$-th term of $1, 11, 111, \ldots$ is:
$$\frac{10^k - 1}{9}$$

**Step 2: Sum the series using this form.**

$$S_n = 3 \sum_{k=1}^{n} \frac{10^k - 1}{9} = \frac{3}{9} \sum_{k=1}^{n} (10^k - 1) = \frac{1}{3}\left[\sum_{k=1}^{n} 10^k - \sum_{k=1}^{n} 1\right]$$

**Step 3: Evaluate each sum separately.**

The sum $\sum_{k=1}^{n} 10^k = 10 + 10^2 + \ldots + 10^n$ is a geometric series with first term $a = 10$, common ratio $r = 10$, and $n$ terms:
$$\sum_{k=1}^{n} 10^k = \frac{10(10^n - 1)}{10 - 1} = \frac{10(10^n - 1)}{9}$$

The sum $\sum_{k=1}^{n} 1 = n$.

**Step 4: Substitute back.**

$$S_n = \frac{1}{3}\left[\frac{10(10^n - 1)}{9} - n\right] = \frac{1}{3} \cdot \frac{10(10^n - 1) - 9n}{9}$$

$$\boxed{S_n = \frac{10(10^n - 1) - 9n}{27}}$$

**Step 5: Verify the formula.**

For $n = 1$: $S_1 = \dfrac{10(10 - 1) - 9(1)}{27} = \dfrac{90 - 9}{27} = \dfrac{81}{27} = 3$. ✓ (matches the first term, $3$)

For $n = 2$: $S_2 = \dfrac{10(100 - 1) - 9(2)}{27} = \dfrac{990 - 18}{27} = \dfrac{972}{27} = 36$. ✓ (matches $3 + 33 = 36$)

For $n = 3$: $S_3 = \dfrac{10(1000 - 1) - 9(3)}{27} = \dfrac{9990 - 27}{27} = \dfrac{9963}{27} = 369$. ✓ (matches $3 + 33 + 333 = 369$)

The formula checks out in all three cases.

**Answer:**
$$\mathbf{S_n = \dfrac{10(10^n - 1) - 9n}{27}}$$
