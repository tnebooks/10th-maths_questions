## The excluded value of the rational expression $\dfrac{x^3 + 8}{x^2 - 2x - 8}$ is

---

#### A rational expression $\frac{p(x)}{q(x)}$ in its lowest terms is undefined for values of $x$ that make the denominator zero ($q(x) = 0$). These values are called excluded values.

Set the denominator equal to zero:
$$x^2 - 2x - 8 = 0$$

Factorize the quadratic expression:
$$(x - 4)(x + 2) = 0$$
$$x - 4 = 0 \implies x = 4$$
$$x + 2 = 0 \implies x = -2$$

The excluded values are $4$ and $-2$. Among the given options ($8$, $2$, $4$, $1$), the value present is $4$.

**Answer:**
$$\mathbf{4}$$
