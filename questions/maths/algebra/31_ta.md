## $3+33+333+........$ என்ற தொடர்வரிசையின் முதல் $n$ உறுப்புகளின் கூடுதல் காண்க.

---

#### கொடுக்கப்பட்ட தொடர் $3 + 33 + 333 + \ldots$ ஆகும், $n$ உறுப்புகள் வரை. இந்தத் தொடரின் ஒவ்வொரு உறுப்பும் நேரடியாக கூட்டுத் தொடர் அல்லது பெருக்குத் தொடர் அல்ல, ஆனால் ஒவ்வொரு உறுப்பையும் $3$ என்பதை $1$-களின் தொடராக பெருக்கியதாக எழுதலாம்: $3 = 3(1)$, $33 = 3(11)$, $333 = 3(111)$, மற்றும் தொடரும். எனவே கூடுதல்:
$$S_n = 3(1 + 11 + 111 + \ldots n \text{ உறுப்புகள் வரை})$$

**படி 1: ஒவ்வொரு உறுப்பையும் 10-ன் அடுக்குகள் கொண்டு எழுதுதல்.**

அடைப்புக்குள் உள்ள ஒவ்வொரு உறுப்பையும் $9$ ஆல் வகுக்கப்பட்ட $10$-ன் அடுக்குகளின் கூட்டுத்தொகையாக எழுதலாம், ஏனெனில் $9$ ஆல் பெருக்கினால் $1$-களின் தொடர் $10^k - 1$ ஆக மாறும்:
$$1 = \frac{10 - 1}{9}, \quad 11 = \frac{100 - 1}{9}, \quad 111 = \frac{1000 - 1}{9}, \ \ldots$$

பொதுவாக, $1, 11, 111, \ldots$ தொடரின் $k$-ஆவது உறுப்பு:
$$\frac{10^k - 1}{9}$$

**படி 2: இந்த வடிவத்தைக் கொண்டு தொடரைக் கூட்டுதல்.**
$$S_n = 3 \sum_{k=1}^{n} \frac{10^k - 1}{9} = \frac{3}{9} \sum_{k=1}^{n} (10^k - 1) = \frac{1}{3}\left[\sum_{k=1}^{n} 10^k - \sum_{k=1}^{n} 1\right]$$

**படி 3: ஒவ்வொரு கூட்டுத்தொகையையும் தனித்தனியே கணக்கிடுதல்.**

$\sum_{k=1}^{n} 10^k = 10 + 10^2 + \ldots + 10^n$ என்பது முதல் உறுப்பு $a = 10$, பொது விகிதம் $r = 10$, $n$ உறுப்புகளைக் கொண்ட ஒரு பெருக்குத் தொடர் ஆகும்:
$$\sum_{k=1}^{n} 10^k = \frac{10(10^n - 1)}{10 - 1} = \frac{10(10^n - 1)}{9}$$

$\sum_{k=1}^{n} 1 = n$ ஆகும்.

**படி 4: மீண்டும் பிரதியிடுதல்.**
$$S_n = \frac{1}{3}\left[\frac{10(10^n - 1)}{9} - n\right] = \frac{1}{3} \cdot \frac{10(10^n - 1) - 9n}{9}$$
$$\boxed{S_n = \frac{10(10^n - 1) - 9n}{27}}$$

**படி 5: வாய்பாட்டைச் சரிபார்த்தல்.**

$n = 1$ ஆக இருக்கும்போது: $S_1 = \dfrac{10(10 - 1) - 9(1)}{27} = \dfrac{90 - 9}{27} = \dfrac{81}{27} = 3$. ✓ (முதல் உறுப்பு $3$ உடன் பொருந்துகிறது)

$n = 2$ ஆக இருக்கும்போது: $S_2 = \dfrac{10(100 - 1) - 9(2)}{27} = \dfrac{990 - 18}{27} = \dfrac{972}{27} = 36$. ✓ ($3 + 33 = 36$ உடன் பொருந்துகிறது)

$n = 3$ ஆக இருக்கும்போது: $S_3 = \dfrac{10(1000 - 1) - 9(3)}{27} = \dfrac{9990 - 27}{27} = \dfrac{9963}{27} = 369$. ✓ ($3 + 33 + 333 = 369$ உடன் பொருந்துகிறது)

வாய்பாடு மூன்று நிலைகளிலும் சரியாக பொருந்துகிறது.

**கையெழுத்து விடைத்திறவுகோல் பற்றிய குறிப்பு:** திறவுகோலின் இடைநிலைக் கோடு "$S_n = \frac{1}{9}\left[\frac{10(10^n-1)}{9} - n\right]$" எனக் காட்டுகிறது — முன்னணி மடங்கு $\frac13$ ஆக இருக்க வேண்டும் ($\frac{3}{9}=\frac13$ என்பதால், $\frac19$ அல்ல); இதை சரியாகத் தொடர்ந்தால் கீழே உள்ள இறுதி வாய்பாட்டையே தரும், இதை $n=1,2,3$ இல் நேரடியாகப் பிரதியிட்டு சுயாதீனமாக உறுதி செய்யப்பட்டது.

**விடை:**
$$\mathbf{S_n = \dfrac{10(10^n - 1) - 9n}{27}}$$
