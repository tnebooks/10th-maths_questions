## If the roots of the quadratic equation $kx^2-(8k+4)x+81=0$ are real and equal, find the value of $k$.

---

#### For a quadratic equation $ax^2+bx+c=0$ to have real and equal roots, its discriminant must be zero: $\Delta = b^2 - 4ac = 0$.

Comparing $kx^2-(8k+4)x+81=0$ with $ax^2+bx+c=0$:
$$a = k, \quad b = -(8k+4), \quad c = 81$$

**Step 1: Set the discriminant to zero.**
$$b^2 - 4ac = 0$$
$$[-(8k+4)]^2 - 4(k)(81) = 0$$
$$(8k+4)^2 - 324k = 0$$

**Step 2: Expand $(8k+4)^2$.**
$$(8k+4)^2 = 64k^2 + 64k + 16$$

So:
$$64k^2 + 64k + 16 - 324k = 0$$
$$64k^2 - 260k + 16 = 0$$

**Step 3: Simplify by dividing throughout by $4$.**
$$16k^2 - 65k + 4 = 0$$

**Step 4: Factorize.**

We need two numbers that multiply to $16 \times 4 = 64$ and add to $-65$: these are $-64$ and $-1$.
$$16k^2 - 64k - k + 4 = 0$$
$$16k(k - 4) - 1(k - 4) = 0$$
$$(16k - 1)(k - 4) = 0$$

So:
$$k = \frac{1}{16} \quad \text{or} \quad k = 4$$

**Step 5: Check both values are valid (reject $k=0$ since that would make the equation linear, not quadratic — neither root does, so both are admissible).**

For $k=4$: $a=4\ne0$, $b=-(8(4)+4)=-36$, $c=81$.
$$\Delta = (-36)^2 - 4(4)(81) = 1296 - 1296 = 0 \checkmark$$

For $k=\dfrac{1}{16}$: $a=\dfrac1{16}\ne0$, $b=-\left(8\cdot\dfrac1{16}+4\right)=-\dfrac{9}{2}$, $c=81$.
$$\Delta = \left(-\frac{9}{2}\right)^2 - 4\left(\frac{1}{16}\right)(81) = \frac{81}{4} - \frac{81}{4} = 0 \checkmark$$

Both values make $a \ne 0$ and give discriminant exactly zero, so **both are mathematically valid solutions**.

**Note on the handwritten answer key:** the key shows the same factorization $(16k-1)(k-4)=0$ but states only $k=\dfrac{1}{16}$ as the final answer. Checking both roots back against the discriminant condition (Step 5 above) shows $k=4$ is equally valid — it was likely dropped by the key's author, not excluded by any mathematical requirement. Both values should be reported.

**Answer:**
$$\mathbf{k = 4 \ \text{or} \ k = \frac{1}{16}}$$
