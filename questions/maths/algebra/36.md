## $y^2+\dfrac{1}{y^2}$ is not equal to

---

#### Check each option against $y^2+\dfrac{1}{y^2}$ by expanding it directly.

**Option $\dfrac{y^4+1}{y^2}$:**
$$\frac{y^4+1}{y^2} = \frac{y^4}{y^2}+\frac{1}{y^2} = y^2+\frac{1}{y^2}$$
This **is equal** to the given expression.

**Option $\left(y-\dfrac{1}{y}\right)^2+2$:**

Using $(a-b)^2 = a^2-2ab+b^2$ with $a=y, b=\dfrac1y$:
$$\left(y-\frac{1}{y}\right)^2 = y^2 - 2\cdot y\cdot\frac1y + \frac{1}{y^2} = y^2-2+\frac{1}{y^2}$$
Adding $2$:
$$\left(y-\frac{1}{y}\right)^2+2 = y^2-2+\frac{1}{y^2}+2 = y^2+\frac{1}{y^2}$$
This **is equal** to the given expression.

**Option $\left(y+\dfrac{1}{y}\right)^2-2$:**

Using $(a+b)^2 = a^2+2ab+b^2$:
$$\left(y+\frac{1}{y}\right)^2 = y^2+2+\frac{1}{y^2}$$
Subtracting $2$:
$$\left(y+\frac{1}{y}\right)^2-2 = y^2+2+\frac{1}{y^2}-2 = y^2+\frac{1}{y^2}$$
This **is equal** to the given expression.

**Option $\left(y+\dfrac{1}{y}\right)^2$ (without any adjustment):**
$$\left(y+\frac{1}{y}\right)^2 = y^2+2+\frac{1}{y^2}$$
This differs from $y^2+\dfrac{1}{y^2}$ by $+2$, so it is **not equal**.

**Answer:** $\left(y+\dfrac{1}{y}\right)^2$ is **not** equal to $y^2+\dfrac{1}{y^2}$.
