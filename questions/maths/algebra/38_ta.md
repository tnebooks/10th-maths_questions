## $3+33+333+\ldots$ தொடரின் $n$ உறுப்புகள் வரையிலான கூடுதலைக் காண்க.

---

#### $3, 33, 333, \ldots$ தொடரின் ஒவ்வொரு உறுப்பும் $1$ களால் ஆன எண்களின் $3$ மடங்காக உள்ளது: $3=3(1), 33=3(11), 333=3(111)$, இப்படியே. எனவே:
$$S_n = 3(1+11+111+\cdots \text{to } n \text{ உறுப்புகள்})$$

**படி 1: $(1+11+111+\cdots)$ ஐ $10$ இன் அடுக்குகள் கொண்டு மறுஎழுதுதல்.**

$9$ ஆல் பெருக்கி வகுக்க:
$$1+11+111+\cdots = \frac{1}{9}(9+99+999+\cdots \text{to } n \text{ உறுப்புகள்})$$

$9, 99, 999, \ldots$ ஒவ்வொரு உறுப்பையும் $(10-1), (100-1), (1000-1), \ldots$ எனவும், அதாவது $k=1,2,\ldots,n$ க்கு $(10^k-1)$ எனவும் எழுதலாம்:
$$9+99+999+\cdots = (10^1-1)+(10^2-1)+(10^3-1)+\cdots+(10^n-1)$$
$$= (10^1+10^2+\cdots+10^n) - n$$

**படி 2: வர்க்க விகிதத் தொடர் $10^1+10^2+\cdots+10^n$ ஐக் கூட்டுதல்.**

இது முதல் உறுப்பு $10$, பொது விகிதம் $10$, $n$ உறுப்புகள் கொண்ட GP ஆகும்:
$$10^1+10^2+\cdots+10^n = \frac{10(10^n-1)}{10-1} = \frac{10(10^n-1)}{9}$$

எனவே:
$$9+99+999+\cdots = \frac{10(10^n-1)}{9} - n$$

**படி 3: காரணிகளை இணைத்தல்.**
$$1+11+111+\cdots = \frac{1}{9}\left[\frac{10(10^n-1)}{9} - n\right] = \frac{10(10^n-1)-9n}{81}$$

$$S_n = 3\times\frac{10(10^n-1)-9n}{81} = \frac{10(10^n-1)-9n}{27}$$

**படி 4: சரிபார்ப்பு.**

$n=1$ க்கு: $S_1 = \dfrac{10(10-1)-9(1)}{27} = \dfrac{90-9}{27} = \dfrac{81}{27} = 3$ ✓ (முதல் உறுப்பு $3$ உடன் பொருந்துகிறது).

$n=2$ க்கு: $S_2 = \dfrac{10(100-1)-9(2)}{27} = \dfrac{990-18}{27} = \dfrac{972}{27} = 36$ ✓ ($3+33=36$ உடன் பொருந்துகிறது).

**விடை:**
$$\mathbf{S_n = \dfrac{10(10^n-1)-9n}{27}}$$
