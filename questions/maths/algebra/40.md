## If $\alpha$ and $\beta$ are the roots of $x^2+7x+10=0$, find the values of: i) $\alpha^2+\beta^2$ ii) $\dfrac{\alpha}{\beta}+\dfrac{\beta}{\alpha}$

---

#### Comparing $x^2+7x+10=0$ with the standard form $ax^2+bx+c=0$: $a=1,\ b=7,\ c=10$.

By the relation between roots and coefficients:
$$\alpha+\beta = -\frac{b}{a} = -\frac{7}{1} = -7, \qquad \alpha\beta = \frac{c}{a} = \frac{10}{1} = 10$$

**i) Finding $\alpha^2+\beta^2$:**

Using the identity $\alpha^2+\beta^2 = (\alpha+\beta)^2-2\alpha\beta$:
$$\alpha^2+\beta^2 = (-7)^2 - 2(10) = 49-20 = 29$$

**ii) Finding $\dfrac{\alpha}{\beta}+\dfrac{\beta}{\alpha}$:**

Combine over a common denominator:
$$\frac{\alpha}{\beta}+\frac{\beta}{\alpha} = \frac{\alpha^2+\beta^2}{\alpha\beta}$$

Substitute the values found above:
$$= \frac{29}{10}$$

**Step: Verify using the actual roots.**

Factorizing $x^2+7x+10=0$: we need two numbers multiplying to $10$ and adding to $7$: these are $2$ and $5$.
$$x^2+2x+5x+10=0 \implies x(x+2)+5(x+2)=0 \implies (x+2)(x+5)=0$$
So $\alpha=-2,\ \beta=-5$ (or vice versa).

Check i): $\alpha^2+\beta^2 = (-2)^2+(-5)^2 = 4+25=29$ ✓

Check ii): $\dfrac{\alpha}{\beta}+\dfrac{\beta}{\alpha} = \dfrac{-2}{-5}+\dfrac{-5}{-2} = \dfrac{2}{5}+\dfrac{5}{2} = \dfrac{4+25}{10}=\dfrac{29}{10}$ ✓

**Answer:**
$$\mathbf{\text{i) } \alpha^2+\beta^2 = 29 \qquad \text{ii) } \frac{\alpha}{\beta}+\frac{\beta}{\alpha} = \frac{29}{10}}$$
