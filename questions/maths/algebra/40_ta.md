## $x^2+7x+10=0$ எனும் சமன்பாட்டின் மூலங்கள் $\alpha$ மற்றும் $\beta$ எனில், பின்வருவனவற்றின் மதிப்புகளைக் காண்க: i) $\alpha^2+\beta^2$ ii) $\dfrac{\alpha}{\beta}+\dfrac{\beta}{\alpha}$

---

#### $x^2+7x+10=0$ ஐ $ax^2+bx+c=0$ எனும் பொது வடிவத்துடன் ஒப்பிட: $a=1,\ b=7,\ c=10$.

மூலங்களுக்கும் கெழுக்களுக்கும் இடையேயான தொடர்பின்படி:
$$\alpha+\beta = -\frac{b}{a} = -\frac{7}{1} = -7, \qquad \alpha\beta = \frac{c}{a} = \frac{10}{1} = 10$$

**i) $\alpha^2+\beta^2$ ஐக் காணுதல்:**

$\alpha^2+\beta^2 = (\alpha+\beta)^2-2\alpha\beta$ என்ற முற்றொருமையைப் பயன்படுத்த:
$$\alpha^2+\beta^2 = (-7)^2 - 2(10) = 49-20 = 29$$

**ii) $\dfrac{\alpha}{\beta}+\dfrac{\beta}{\alpha}$ ஐக் காணுதல்:**

பொதுவான வகுத்தி கொண்டு இணைக்க:
$$\frac{\alpha}{\beta}+\frac{\beta}{\alpha} = \frac{\alpha^2+\beta^2}{\alpha\beta}$$

மேலே கண்ட மதிப்புகளைப் பிரதியிட:
$$= \frac{29}{10}$$

**படி: உண்மையான மூலங்களைக் கொண்டு சரிபார்த்தல்.**

$x^2+7x+10=0$ ஐ காரணிப்படுத்த: பெருக்கல் $10$ ஆகவும் கூட்டுத்தொகை $7$ ஆகவும் தரும் இரு எண்கள்: $2$ மற்றும் $5$.
$$x^2+2x+5x+10=0 \implies x(x+2)+5(x+2)=0 \implies (x+2)(x+5)=0$$
எனவே $\alpha=-2,\ \beta=-5$ (அல்லது மாற்றியும்).

சரிபார்ப்பு i): $\alpha^2+\beta^2 = (-2)^2+(-5)^2 = 4+25=29$ ✓

சரிபார்ப்பு ii): $\dfrac{\alpha}{\beta}+\dfrac{\beta}{\alpha} = \dfrac{-2}{-5}+\dfrac{-5}{-2} = \dfrac{2}{5}+\dfrac{5}{2} = \dfrac{4+25}{10}=\dfrac{29}{10}$ ✓

**விடை:**
$$\mathbf{\text{i) } \alpha^2+\beta^2 = 29 \qquad \text{ii) } \frac{\alpha}{\beta}+\frac{\beta}{\alpha} = \frac{29}{10}}$$
