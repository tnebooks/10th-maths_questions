## If $36x^4 - 60x^3 + 61x^2 - mx + n$ is a perfect square, find the values of $m$ and $n$.

---

#### Use the division method for polynomials:

1. $\sqrt{36x^4} = 6x^2$.
   Subtract $36x^4$: brings down $-60x^3 + 61x^2$.
2. Double $6x^2 \implies 12x^2$.
   $\dfrac{-60x^3}{12x^2} = -5x$.
   Multiply $(12x^2 - 5x)(-5x) = -60x^3 + 25x^2$.
   Subtracting gives $36x^2 - mx + n$.
3. Double quotient $6x^2 - 5x \implies 12x^2 - 10x$.
   $\dfrac{36x^2}{12x^2} = 3$.
   Multiply $(12x^2 - 10x + 3)(3) = 36x^2 - 30x + 9$.

Since the given polynomial is a perfect square, the remainder must be $0$:
$$(36x^2 - mx + n) - (36x^2 - 30x + 9) = 0$$
$$-mx + 30x = 0 \implies m = 30$$
Wait, let's verify signs:
If polynomial is $36x^4 - 60x^3 + 61x^2 - mx + n$, then $-mx - (-30x) = 0 \implies -m + 30 = 0 \implies m = 30$, and $n - 9 = 0 \implies n = 9$.
Wait! If $-mx$ matches $-30x$, then $m = 30$. If expression was $+mx$, $m=-30$. Here $-mx = -30x \implies m = 30$.
Let's double-check:
$(6x^2 - 5x + 3)^2 = 36x^4 + 25x^2 + 9 - 60x^3 + 36x^2 - 30x = 36x^4 - 60x^3 + 61x^2 - 30x + 9$.
Comparing with $36x^4 - 60x^3 + 61x^2 - mx + n$:
$-m = -30 \implies m = 30, \quad n = 9$.

**Answer:**
$$\mathbf{m = 30, \quad n = 9}$$
