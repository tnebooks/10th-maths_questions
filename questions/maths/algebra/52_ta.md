## மூன்று மாறிகளில் அமைந்த நேரியல் சமன்பாட்டுத் தொகுப்பைத் தீர்க்க:
$$\frac{1}{2x} + \frac{1}{4y} - \frac{1}{3z} = \frac{1}{4}$$
$$\frac{1}{x} = \frac{1}{3y}$$
$$\frac{1}{x} - \frac{1}{5y} + \frac{4}{z} = 2\frac{2}{15}$$

---

#### $\dfrac{1}{x} = p$, $\dfrac{1}{y} = q$, மற்றும் $\dfrac{1}{z} = r$ என்க.

கொடுக்கப்பட்ட சமன்பாடுகள்:
1. $\dfrac{p}{2} + \dfrac{q}{4} - \dfrac{r}{3} = \dfrac{1}{4} \implies 6p + 3q - 4r = 3 \quad \text{--- (1)}$
2. $p = \dfrac{q}{3} \implies q = 3p \quad \text{--- (2)}$
3. $p - \dfrac{q}{5} + 4r = \dfrac{32}{15} \implies 15p - 3q + 60r = 32 \quad \text{--- (3)}$

(2)-லிருந்து $q = 3p$-ஐ (1)-ல் பிரதியிட:
$$6p + 3(3p) - 4r = 3 \implies 15p - 4r = 3 \quad \text{--- (4)}$$

(2)-லிருந்து $q = 3p$-ஐ (3)-ல் பிரதியிட:
$$15p - 3(3p) + 60r = 32 \implies 6p + 60r = 32 \implies 3p + 30r = 16 \quad \text{--- (5)}$$

(5)-ஐ 5-ஆல் பெருக்க:
$$15p + 150r = 80 \quad \text{--- (6)}$$

(6)-லிருந்து (4)-ஐக் கழிக்க:
$$(15p + 150r) - (15p - 4r) = 80 - 3$$
$$154r = 77 \implies r = \frac{77}{154} = \frac{1}{2}$$

$r = \dfrac{1}{2}$-ஐ (4)-ல் பிரதியிட:
$$15p - 4\left(\frac{1}{2}\right) = 3 \implies 15p - 2 = 3 \implies 15p = 5 \implies p = \frac{1}{3}$$

(2)-லிருந்து:
$$q = 3p = 3\left(\frac{1}{3}\right) = 1$$

எனவே:
$$x = \frac{1}{p} = 3, \quad y = \frac{1}{q} = 1, \quad z = \frac{1}{r} = 2$$

**விடை:**
$$\mathbf{x = 3, \quad y = 1, \quad z = 2}$$
