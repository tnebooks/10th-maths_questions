## தாத்தா, தந்தை, வாணி ஆகிய மூவரின் சராசரி வயது $53$ ஆகும். தாத்தாவின் வயதில் பாதி, தந்தையின் வயதில் மூன்றில் ஒரு பங்கு மற்றும் வாணியின் வயதில் நான்கில் ஒரு பங்கு ஆகியவற்றின் கூடுதல் $65$ ஆகும். நான்கு ஆண்டுகளுக்கு முன் தாத்தாவின் வயது வாணியின் வயதைப் போல் நான்கு மடங்கு எனில் மூவரின் தற்போதைய வயதைக் காண்க.

---

#### வாணி, தந்தை மற்றும் தாத்தாவின் தற்போதைய வயதுகள் முறையே $x, y, z$ ஆண்டுகள் என்க.

**படி 1: கொடுக்கப்பட்ட விவரங்களிலிருந்து சமன்பாடுகளை அமைக்க.**

1. மூவரின் சராசரி வயது $53$:
$$\frac{x + y + z}{3} = 53 \implies x + y + z = 159 \quad \text{--- (1)}$$

2. வாணியின் வயதில் $\frac{1}{4}$ பங்கு, தந்தையின் வயதில் $\frac{1}{3}$ பங்கு, தாத்தாவின் வயதில் $\frac{1}{2}$ பங்கு ஆகியவற்றின் கூடுதல் $65$:
$$\frac{x}{4} + \frac{y}{3} + \frac{z}{2} = 65$$
$4, 3, 2$-ன் மீ.பொ.ம $12$-ஆல் பெருக்க:
$$3x + 4y + 6z = 780 \quad \text{--- (2)}$$

3. நான்கு ஆண்டுகளுக்கு முன், தாத்தாவின் வயது வாணியின் வயதைப் போல் $4$ மடங்கு:
$$z - 4 = 4(x - 4)$$
$$z - 4 = 4x - 16 \implies 4x - z = 12 \implies z = 4x - 12 \quad \text{--- (3)}$$

**படி 2: நேரியல் சமன்பாட்டுத் தொகுப்பைத் தீர்க்க.**

(3)-ஐ (1)-ல் பிரதியிட:
$$x + y + (4x - 12) = 159$$
$$5x + y = 171 \implies y = 171 - 5x \quad \text{--- (4)}$$

(3) மற்றும் (4)-ஐ (2)-ல் பிரதியிட:
$$3x + 4(171 - 5x) + 6(4x - 12) = 780$$
$$3x + 684 - 20x + 24x - 72 = 780$$
$$7x + 612 = 780$$
$$7x = 168 \implies x = 24$$

$x = 24$-ஐ (4) மற்றும் (3)-ல் பிரதியிட:
$$y = 171 - 5(24) = 171 - 120 = 51$$
$$z = 4(24) - 12 = 96 - 12 = 84$$

**சரிபார்த்தல்:**
- சராசரி: $\frac{24 + 51 + 84}{3} = \frac{159}{3} = 53$ ✓
- $\frac{24}{4} + \frac{51}{3} + \frac{84}{2} = 6 + 17 + 42 = 65$ ✓
- $4$ ஆண்டுகளுக்கு முன்: $84 - 4 = 80 = 4(24 - 4) = 4(20)$ ✓

**விடை:**
$$\mathbf{வாணியின்\ வயது = 24\ ஆண்டுகள், \quad தந்தையின்\ வயது = 51\ ஆண்டுகள், \quad தாத்தாவின்\ வயது = 84\ ஆண்டுகள்}$$
