## நிலையான நீரில் $18\text{ கி.மீ/மணி}$ வேகத்தில் செல்லும் ஓர் இயந்திரப் படகானது $24\text{ கி.மீ}$ தூரத்தை நீரின் திசையில் கடக்கும் நேரத்தை விட நீரின் எதிர்திசையில் கடக்க கூடுதலாக $1\text{ மணி}$ நேரம் தேவைப்படுகிறது எனில் நீரின் வேகம் காண்க.

---

#### நீரோட்டத்தின் வேகம் $s\text{ கி.மீ/மணி}$ என்க.

- நிலையான நீரில் படகின் வேகம் = $18\text{ கி.மீ/மணி}$
- நீரின் எதிர்திசையில் (எதிர்நீச்சல்) படகின் வேகம் = $(18 - s)\text{ கி.மீ/மணி}$
- நீரின் திசையில் (ஒழுக்கு) படகின் வேகம் = $(18 + s)\text{ கி.மீ/மணி}$
- கடந்த தூரம் = $24\text{ கி.மீ}$

**படி 1: காலத்திற்கான கோவைகளை அமைக்க.**
$$\text{எதிர்திசையில் செல்ல ஆகும் நேரம்}, \ t_1 = \frac{24}{18 - s}$$
$$\text{நீரின் திசையில் செல்ல ஆகும் நேரம்}, \ t_2 = \frac{24}{18 + s}$$

**படி 2: இருபடிச் சமன்பாட்டை அமைத்துத் தீர்க்க.**
கொடுக்கப்பட்ட விவரப்படி, எதிர்திசையில் செல்ல $1\text{ மணி}$ நேரம் கூடுதலாகத் தேவைப்படுகிறது:
$$t_1 - t_2 = 1$$
$$\frac{24}{18 - s} - \frac{24}{18 + s} = 1$$
$$24\left[\frac{(18 + s) - (18 - s)}{(18 - s)(18 + s)}\right] = 1$$
$$24\left[\frac{2s}{324 - s^2}\right] = 1$$
$$48s = 324 - s^2$$
$$s^2 + 48s - 324 = 0$$

இருபடிச் சமன்பாட்டை காரணிப்படுத்த:
பெருக்குத்தொகை $-324$ மற்றும் கூடுதல் $48$ தரும் எண்கள் $54$ மற்றும் $-6$ ஆகும்.
$$(s + 54)(s - 6) = 0$$
$$s + 54 = 0 \implies s = -54$$
$$s - 6 = 0 \implies s = 6$$

நீரோட்டத்தின் வேகம் குறை எண்ணாக இருக்க முடியாது என்பதால், $s = -54$ பொருந்தாது.
எனவே, நீரோட்டத்தின் வேகம் $s = 6\text{ கி.மீ/மணி}$ ஆகும்.

**சரிபார்த்தல்:**
- எதிர்திசை வேகம் = $18 - 6 = 12\text{ கி.மீ/மணி} \implies t_1 = \frac{24}{12} = 2\text{ மணிகள்}$
- நீரின் திசை வேகம் = $18 + 6 = 24\text{ கி.மீ/மணி} \implies t_2 = \frac{24}{24} = 1\text{ மணி}$
- $t_1 - t_2 = 2 - 1 = 1\text{ மணி}$ ✓

**விடை:**
$$\mathbf{6\text{ கி.மீ/மணி}}$$
