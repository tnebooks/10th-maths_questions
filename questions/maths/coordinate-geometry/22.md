## Find the equation of a straight line passing through $(1, -4)$ and having intercepts in the ratio $2:5$.

---

#### Let the $x$-intercept be $a$ and the $y$-intercept be $b$, with $a : b = 2 : 5$. So we can write $a = 2k$ and $b = 5k$ for some constant $k$.

Intercept form of a straight line:
$$\frac{x}{a} + \frac{y}{b} = 1$$

Substituting $a = 2k$, $b = 5k$:
$$\frac{x}{2k} + \frac{y}{5k} = 1$$

Since the line passes through $(1, -4)$, substitute $x = 1$, $y = -4$:
$$\frac{1}{2k} + \frac{-4}{5k} = 1$$

Taking LCM of $2k$ and $5k$, which is $10k$:
$$\frac{5}{10k} - \frac{8}{10k} = 1$$
$$\frac{5 - 8}{10k} = 1$$
$$\frac{-3}{10k} = 1$$
$$-3 = 10k$$
$$k = -\frac{3}{10}$$

So:
$$a = 2k = 2 \times \left(-\frac{3}{10}\right) = -\frac{3}{5}, \qquad b = 5k = 5 \times \left(-\frac{3}{10}\right) = -\frac{3}{2}$$

Substituting back into the intercept form:
$$\frac{x}{-3/5} + \frac{y}{-3/2} = 1$$
$$-\frac{5x}{3} - \frac{2y}{3} = 1$$

Multiplying throughout by $3$:
$$-5x - 2y = 3$$
$$5x + 2y + 3 = 0$$

**Verification:** Substitute $(1, -4)$ into $5x + 2y + 3 = 0$:
$$5(1) + 2(-4) + 3 = 5 - 8 + 3 = 0 \quad \checkmark$$

**Answer:**
$$\mathbf{5x + 2y + 3 = 0}$$
