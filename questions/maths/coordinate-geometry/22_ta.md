## $(1, -4)$ என்ற புள்ளிவழிச் செல்வது, வெட்டுத்துண்டுகளின் விகிதம் $2:5$ உடைய நேர்க்கோட்டின் சமன்பாட்டினைக் காண்க.

---

#### $x$-வெட்டுத்துண்டு $a$ எனவும், $y$-வெட்டுத்துண்டு $b$ எனவும், $a : b = 2 : 5$ எனவும் கொள்வோம். எனவே $a = 2k$, $b = 5k$ என ஒரு மாறிலி $k$-ஐப் பயன்படுத்தி எழுதலாம்.

நேர்க்கோட்டின் வெட்டுத்துண்டு வடிவம்:
$$\frac{x}{a} + \frac{y}{b} = 1$$

$a = 2k$, $b = 5k$ எனப் பிரதியிடுதல்:
$$\frac{x}{2k} + \frac{y}{5k} = 1$$

கோடு $(1, -4)$ வழிச் செல்வதால், $x = 1$, $y = -4$ எனப் பிரதியிடுதல்:
$$\frac{1}{2k} + \frac{-4}{5k} = 1$$

$2k$ மற்றும் $5k$-ன் மீச்சிறு பொதுமடங்கு $10k$:
$$\frac{5}{10k} - \frac{8}{10k} = 1$$
$$\frac{5 - 8}{10k} = 1$$
$$\frac{-3}{10k} = 1$$
$$-3 = 10k$$
$$k = -\frac{3}{10}$$

எனவே:
$$a = 2k = 2 \times \left(-\frac{3}{10}\right) = -\frac{3}{5}, \qquad b = 5k = 5 \times \left(-\frac{3}{10}\right) = -\frac{3}{2}$$

இவற்றை வெட்டுத்துண்டு வடிவத்தில் மீண்டும் பிரதியிடுதல்:
$$\frac{x}{-3/5} + \frac{y}{-3/2} = 1$$
$$-\frac{5x}{3} - \frac{2y}{3} = 1$$

முழுவதையும் $3$ ஆல் பெருக்குதல்:
$$-5x - 2y = 3$$
$$5x + 2y + 3 = 0$$

**சரிபார்ப்பு:** $(1, -4)$-ஐ $5x + 2y + 3 = 0$ இல் பிரதியிடுதல்:
$$5(1) + 2(-4) + 3 = 5 - 8 + 3 = 0 \quad \checkmark$$

**விடை:**
$$\mathbf{5x + 2y + 3 = 0}$$
