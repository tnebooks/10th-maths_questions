## The slope of the line joining $(12, 3)$, $(4, a)$ is $\dfrac{1}{8}$. The value of '$a$' is

---

#### Apply the slope formula to the two given points.

$$(x_1, y_1) = (12, 3), \quad (x_2, y_2) = (4, a)$$

$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{a - 3}{4 - 12} = \frac{a-3}{-8}$$

Given slope $m = \dfrac{1}{8}$:
$$\frac{a - 3}{-8} = \frac{1}{8}$$

Cross-multiplying:
$$8(a - 3) = -8$$
$$a - 3 = -1$$
$$a = 2$$

**Verification:** With $a = 2$, slope $= \dfrac{2-3}{4-12} = \dfrac{-1}{-8} = \dfrac{1}{8}$ $\checkmark$

**Answer:**
$$\mathbf{a = 2}$$
