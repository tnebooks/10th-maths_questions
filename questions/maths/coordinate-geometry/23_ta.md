## $(12,3)$, $(4,a)$ என்ற புள்ளிகளை இணைக்கும் கோட்டின் சாய்வு $\dfrac{1}{8}$ எனில், '$a$'-யின் மதிப்பு

---

#### கொடுக்கப்பட்ட இரு புள்ளிகளுக்குச் சாய்வு சூத்திரத்தைப் பயன்படுத்துவோம்.

$$(x_1, y_1) = (12, 3), \quad (x_2, y_2) = (4, a)$$

$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{a - 3}{4 - 12} = \frac{a-3}{-8}$$

கொடுக்கப்பட்ட சாய்வு $m = \dfrac{1}{8}$:
$$\frac{a - 3}{-8} = \frac{1}{8}$$

குறுக்கு பெருக்கல்:
$$8(a - 3) = -8$$
$$a - 3 = -1$$
$$a = 2$$

**சரிபார்ப்பு:** $a = 2$ எனில், சாய்வு $= \dfrac{2-3}{4-12} = \dfrac{-1}{-8} = \dfrac{1}{8}$ $\checkmark$

**விடை:**
$$\mathbf{a = 2}$$
