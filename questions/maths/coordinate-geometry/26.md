## Find the area of the quadrilateral whose vertices are $(-9, 0)$, $(-8, 6)$, $(-1, -2)$ and $(-6, -3)$.

---

#### Let the vertices taken in order be $(x_1,y_1) = (-9, 0)$, $(x_2,y_2) = (-8, 6)$, $(x_3,y_3) = (-1, -2)$, $(x_4,y_4) = (-6, -3)$.

Area of a quadrilateral with vertices taken in order:
$$\text{Area} = \frac{1}{2} \left| (x_1y_2 - x_2y_1) + (x_2y_3 - x_3y_2) + (x_3y_4 - x_4y_3) + (x_4y_1 - x_1y_4) \right|$$

Computing each term:
$$x_1y_2 - x_2y_1 = (-9)(6) - (-8)(0) = -54 - 0 = -54$$
$$x_2y_3 - x_3y_2 = (-8)(-2) - (-1)(6) = 16 + 6 = 22$$
$$x_3y_4 - x_4y_3 = (-1)(-3) - (-6)(-2) = 3 - 12 = -9$$
$$x_4y_1 - x_1y_4 = (-6)(0) - (-9)(-3) = 0 - 27 = -27$$

Adding these:
$$-54 + 22 + (-9) + (-27) = -68$$

Therefore:
$$\text{Area} = \frac{1}{2}|{-68}| = \frac{68}{2} = 34$$

**Verification (alternate grouping of the same shoelace formula):**
$$\text{Area} = \frac{1}{2}\left| x_1(y_2-y_4)+x_2(y_3-y_1)+x_3(y_4-y_2)+x_4(y_1-y_3)\right|$$
$$= \frac{1}{2}\left|(-9)(9) + (-8)(-2) + (-1)(-9) + (-6)(2)\right|$$
$$= \frac{1}{2}\left|-81+16+9-12\right| = \frac{1}{2}|-68| = 34$$

Both groupings of the shoelace formula agree, confirming the area independently.

**Answer:**
$$\mathbf{\text{Area} = 34 \text{ sq. units}}$$
