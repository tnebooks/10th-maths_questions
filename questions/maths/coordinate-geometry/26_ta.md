## $(-9, 0)$, $(-8, 6)$, $(-1, -2)$ மற்றும் $(-6, -3)$ என்ற புள்ளிகளை முனைகளாகக் கொண்ட நாற்கரத்தின் பரப்பைக் காண்க.

---

#### முனைப்புள்ளிகளை வரிசையில் $(x_1,y_1) = (-9, 0)$, $(x_2,y_2) = (-8, 6)$, $(x_3,y_3) = (-1, -2)$, $(x_4,y_4) = (-6, -3)$ என எடுத்துக் கொள்வோம்.

வரிசையில் கொடுக்கப்பட்ட முனைப்புள்ளிகளைக் கொண்ட நாற்கரத்தின் பரப்பு:
$$\text{பரப்பு} = \frac{1}{2} \left| (x_1y_2 - x_2y_1) + (x_2y_3 - x_3y_2) + (x_3y_4 - x_4y_3) + (x_4y_1 - x_1y_4) \right|$$

ஒவ்வொரு உறுப்பையும் கணக்கிடுதல்:
$$x_1y_2 - x_2y_1 = (-9)(6) - (-8)(0) = -54 - 0 = -54$$
$$x_2y_3 - x_3y_2 = (-8)(-2) - (-1)(6) = 16 + 6 = 22$$
$$x_3y_4 - x_4y_3 = (-1)(-3) - (-6)(-2) = 3 - 12 = -9$$
$$x_4y_1 - x_1y_4 = (-6)(0) - (-9)(-3) = 0 - 27 = -27$$

இவற்றைக் கூட்டுதல்:
$$-54 + 22 + (-9) + (-27) = -68$$

எனவே:
$$\text{பரப்பு} = \frac{1}{2}|{-68}| = \frac{68}{2} = 34$$

**சரிபார்ப்பு (அதே shoelace சூத்திரத்தின் மாற்று தொகுப்பு):**
$$\text{பரப்பு} = \frac{1}{2}\left| x_1(y_2-y_4)+x_2(y_3-y_1)+x_3(y_4-y_2)+x_4(y_1-y_3)\right|$$
$$= \frac{1}{2}\left|(-9)(9) + (-8)(-2) + (-1)(-9) + (-6)(2)\right|$$
$$= \frac{1}{2}\left|-81+16+9-12\right| = \frac{1}{2}|-68| = 34$$

இரு தொகுப்புகளும் ஒரே பரப்பைத் தருகின்றன, இது சுயேச்சையாக உறுதி செய்கிறது.

**விடை:**
$$\mathbf{\text{பரப்பு} = 34 \text{ ச.அலகு}}$$
