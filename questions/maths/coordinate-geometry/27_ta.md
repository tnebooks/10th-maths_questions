## $5x-6y=2$ மற்றும் $3x+2y=10$ ஆகிய நேர்க்கோடுகள் சந்திக்கும் புள்ளி வழியாகவும் $4x-7y+13=0$ என்ற நேர்க்கோட்டிற்குச் செங்குத்தாகவும் அமையும் நேர்க்கோட்டின் சமன்பாட்டைக் காண்க.

---

#### படி 1: $5x - 6y = 2$ மற்றும் $3x + 2y = 10$ ஆகிய கோடுகளின் வெட்டுப்புள்ளியைக் காண்க.

இரண்டாம் சமன்பாட்டிலிருந்து:
$$3x + 2y = 10 \implies y = \frac{10 - 3x}{2}$$

இதை முதல் சமன்பாட்டில் பிரதியிடுதல்:
$$5x - 6\left(\frac{10-3x}{2}\right) = 2$$
$$5x - 3(10 - 3x) = 2$$
$$5x - 30 + 9x = 2$$
$$14x = 32$$
$$x = \frac{32}{14} = \frac{16}{7}$$

மீண்டும் பிரதியிடுதல்:
$$y = \frac{10 - 3\left(\frac{16}{7}\right)}{2} = \frac{\frac{70-48}{7}}{2} = \frac{\frac{22}{7}}{2} = \frac{22}{14} = \frac{11}{7}$$

எனவே வெட்டுப்புள்ளி $\left(\dfrac{16}{7}, \dfrac{11}{7}\right)$.

**சரிபார்ப்பு:** $5\left(\dfrac{16}{7}\right) - 6\left(\dfrac{11}{7}\right) = \dfrac{80}{7} - \dfrac{66}{7} = \dfrac{14}{7} = 2$ $\checkmark$; $3\left(\dfrac{16}{7}\right) + 2\left(\dfrac{11}{7}\right) = \dfrac{48}{7} + \dfrac{22}{7} = \dfrac{70}{7} = 10$ $\checkmark$

#### படி 2: தேவையான கோட்டின் சாய்வைக் காண்க.

$4x - 7y + 13 = 0$ கோட்டின் சாய்வு:
$$m_1 = -\frac{4}{-7} = \frac{4}{7}$$

இதற்குச் செங்குத்தான கோட்டிற்கு, $m_1 \times m_2 = -1$:
$$\frac{4}{7} \times m_2 = -1 \implies m_2 = -\frac{7}{4}$$

#### படி 3: $\left(\dfrac{16}{7}, \dfrac{11}{7}\right)$ வழியாகவும், சாய்வு $-\dfrac{7}{4}$ உடையதாகவும் சமன்பாட்டை எழுதுதல்.

$$y - \frac{11}{7} = -\frac{7}{4}\left(x - \frac{16}{7}\right)$$

இரு பக்கங்களையும் $28$ (7, 4-ன் மீச்சிறு பொதுமடங்கு) ஆல் பெருக்குதல்:
$$28y - 44 = -49\left(x - \frac{16}{7}\right)$$
$$28y - 44 = -49x + 112$$
$$49x + 28y - 44 - 112 = 0$$
$$49x + 28y - 156 = 0$$

**சரிபார்ப்பு:** $\left(\dfrac{16}{7}, \dfrac{11}{7}\right)$-ஐ பிரதியிடுதல்:
$$49\left(\frac{16}{7}\right) + 28\left(\frac{11}{7}\right) - 156 = 112 + 44 - 156 = 0 \quad \checkmark$$

செங்குத்துத் தன்மையையும் சரிபார்த்தல்: $49x+28y-156=0$-ன் சாய்வு $-\dfrac{49}{28}=-\dfrac{7}{4}$; $\dfrac{4}{7}$ உடன் பெருக்கற்பலன் $-1$. $\checkmark$

**விடை:**
$$\mathbf{49x + 28y - 156 = 0}$$
