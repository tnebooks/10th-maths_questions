## $A(3,-4)$, $B(9,-4)$, $C(5,-7)$ மற்றும் $D(7,-7)$ ஆகிய புள்ளிகள் $ABCD$ என்ற சரிவகத்தை அமைக்கும் எனக் காட்டுக.

---

#### படி 1: சரிவகத்திற்கான நிபந்தனையை நினைவுகூர்வோம்.

ஒரு நாற்கரத்தின் எதிர்ப்பக்கங்களில் **சரியாக ஒரு ஜோடி** மட்டும் இணையாக இருந்தால் (மற்றொரு ஜோடி இணையாக இல்லாவிட்டால்), அது ஒரு **சரிவகம்** ஆகும். இரு ஜோடிகளும் இணையாக இருந்தால் அது இணைகரமாக இருக்கும்.

#### படி 2: $AB$ பக்கத்தின் சாய்வைக் காண்போம்.

$$A(3,-4), \quad B(9,-4)$$
$$m_{AB} = \frac{-4 - (-4)}{9 - 3} = \frac{0}{6} = 0$$

எனவே $AB$ கிடைக்கோடாக உள்ளது.

#### படி 3: $CD$ பக்கத்தின் சாய்வைக் காண்போம்.

$$C(5,-7), \quad D(7,-7)$$
$$m_{CD} = \frac{-7 - (-7)}{7 - 5} = \frac{0}{2} = 0$$

எனவே $CD$-ம் கிடைக்கோடாக உள்ளது.

$m_{AB} = m_{CD} = 0$ என்பதால், $AB \parallel CD$.

#### படி 4: $BC$ பக்கத்தின் சாய்வைக் காண்போம்.

$$B(9,-4), \quad C(5,-7)$$
$$m_{BC} = \frac{-7 - (-4)}{5 - 9} = \frac{-3}{-4} = \frac{3}{4}$$

#### படி 5: $AD$ பக்கத்தின் சாய்வைக் காண்போம்.

$$A(3,-4), \quad D(7,-7)$$
$$m_{AD} = \frac{-7 - (-4)}{7 - 3} = \frac{-3}{4}$$

$m_{BC} = \dfrac{3}{4}$ மற்றும் $m_{AD} = -\dfrac{3}{4}$ என்பதால், $m_{BC} \ne m_{AD}$. எனவே $BC$, $AD$-க்கு இணையாக இல்லை.

#### முடிவு

எதிர்ப்பக்கங்களில் சரியாக ஒரு ஜோடி ($AB$ மற்றும் $CD$) மட்டும் இணையாகவும், மற்றொரு ஜோடி ($BC$ மற்றும் $AD$) இணையாக இல்லாமலும் உள்ளது. எனவே, வரையறையின்படி $ABCD$ ஒரு **சரிவகம்** ஆகும்.

**விடை:**
$$\mathbf{ABCD \text{ ஒரு சரிவகம், ஏனெனில் } AB \parallel CD \text{ (சாய்வு } 0\text{) ஆனால் } BC \nparallel AD}$$
