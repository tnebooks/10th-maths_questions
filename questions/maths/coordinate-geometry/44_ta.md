## ஒரு முக்கோணத்தின் பரப்பு $5\text{ சதுர அலகுகள்}$. $(2, 1)$ மற்றும் $(3, -2)$ அதன் இரு முனைப் புள்ளிகள், $y = x + 3$ என்ற நேர்க்கோட்டின் மீது மூன்றாவது முனைப்புள்ளி அமைந்தால் அதனைக் காண்க.

---

#### முக்கோணத்தின் முனைகள் $A(2, 1)$, $B(3, -2)$, மற்றும் $C(x, y)$ என்க.

மூன்றாவது முனைப்புள்ளி $C(x, y)$ ஆனது $y = x + 3$ என்ற கோட்டின் மீது அமைவதால்:
$$C = (x, x + 3)$$

முக்கோணத்தின் பரப்பு காணும் சூத்திரம்:
$$\text{பரப்பு} = \frac{1}{2} |x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2)| = 5$$

புள்ளிகளைப் பிரதியிட:
$$\frac{1}{2} |2(-2 - (x + 3)) + 3((x + 3) - 1) + x(1 - (-2))| = 5$$
$$|2(-x - 5) + 3(x + 2) + x(3)| = 10$$
$$|-2x - 10 + 3x + 6 + 3x| = 10$$
$$|4x - 4| = 10$$
$$4|x - 1| = 10 \implies |x - 1| = \frac{5}{2}$$

இதிலிருந்து இரண்டு நிலைகள் கிடைக்கின்றன:

**நிலை 1:**
$$x - 1 = \frac{5}{2} \implies x = 1 + \frac{5}{2} = \frac{7}{2}$$
$$y = x + 3 = \frac{7}{2} + 3 = \frac{13}{2}$$
மூன்றாவது முனைப்புள்ளி: $\left(\dfrac{7}{2}, \dfrac{13}{2}\right)$

**நிலை 2:**
$$x - 1 = -\frac{5}{2} \implies x = 1 - \frac{5}{2} = -\frac{3}{2}$$
$$y = x + 3 = -\frac{3}{2} + 3 = \frac{3}{2}$$
மூன்றாவது முனைப்புள்ளி: $\left(-\dfrac{3}{2}, \dfrac{3}{2}\right)$

**விடை:**
$$\mathbf{\left(\frac{7}{2}, \frac{13}{2}\right) \quad \text{அல்லது} \quad \left(-\frac{3}{2}, \frac{3}{2}\right)}$$
