## நாற்கர வடிவ நீச்சல் குளத்தின் கான்கிரீட் உள்முற்றமானது படத்தில் காட்டியுள்ளபடி அமைக்கப்பட்டுள்ளது. வெளிப்புற முனைகள் $A(-4, -8)$, $B(8, -4)$, $C(6, 10)$, $D(-10, 6)$ மற்றும் நீச்சல் குளத்தின் உட்புற முனைகள் $E(-3, -5)$, $F(6, -2)$, $G(3, 7)$, $H(-6, 4)$ எனில், கான்கிரீட் உள்முற்றத்தின் பரப்பைக் காண்க.

---

#### கான்கிரீட் உள்முற்றத்தின் பரப்பானது, வெளிப்புற நாற்கரம் $ABCD$-யின் பரப்பிலிருந்து உட்புற நாற்கர நீச்சல் குளம் $EFGH$-ன் பரப்பைக் கழிப்பதன் மூலம் பெறப்படுகிறது:
$$\text{உள்முற்றத்தின் பரப்பு} = \text{நாற்கரம் } ABCD\text{-ன் பரப்பு} - \text{நாற்கரம் } EFGH\text{-ன் பரப்பு}$$

**படி 1: வெளிப்புற நாற்கரம் $ABCD$-யின் பரப்பு**

முனைகள் கடிகார எதிர் வரிசையில்: $A(-4, -8), B(8, -4), C(6, 10), D(-10, 6)$.
$$\text{பரப்பு} = \frac{1}{2} \left| (x_1 y_2 + x_2 y_3 + x_3 y_4 + x_4 y_1) - (x_2 y_1 + x_3 y_2 + x_4 y_3 + x_1 y_4) \right|$$

$$\Sigma_1 = (-4)(-4) + 8(10) + 6(6) + (-10)(-8) = 16 + 80 + 36 + 80 = 212$$
$$\Sigma_2 = (-8)(8) + (-4)(6) + 10(-10) + 6(-4) = -64 - 24 - 100 - 24 = -212$$

$$\text{நாற்கரம் } ABCD\text{-ன் பரப்பு} = \frac{1}{2} |212 - (-212)| = \frac{1}{2} (424) = 212\text{ ச. அலகுகள்}$$

**படி 2: உட்புற நீச்சல் குளம் $EFGH$-ன் பரப்பு**

முனைகள் கடிகார எதிர் வரிசையில்: $E(-3, -5), F(6, -2), G(3, 7), H(-6, 4)$.
$$\Sigma_1 = (-3)(-2) + 6(7) + 3(4) + (-6)(-5) = 6 + 42 + 12 + 30 = 90$$
$$\Sigma_2 = (-5)(6) + (-2)(3) + 7(-6) + 4(-3) = -30 - 6 - 42 - 12 = -90$$

$$\text{நாற்கரம் } EFGH\text{-ன் பரப்பு} = \frac{1}{2} |90 - (-90)| = \frac{1}{2} (180) = 90\text{ ச. அலகுகள்}$$

**படி 3: உள்முற்றத்தின் பரப்பு**
$$\text{உள்முற்றத்தின் பரப்பு} = 212 - 90 = 122\text{ ச. அலகுகள்}$$

**விடை:**
$$\mathbf{122\text{ ச. அலகுகள்}}$$
