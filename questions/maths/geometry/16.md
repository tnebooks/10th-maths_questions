## In $\triangle LMN$, $\angle L = 60^\circ$, $\angle M = 50^\circ$ and $\triangle LMN \sim \triangle PQR$, then the value of $\angle R$ is

---

#### The sum of the angles of a triangle is $180^\circ$.
In $\triangle LMN$:
$$\angle L + \angle M + \angle N = 180^\circ$$
$$60^\circ + 50^\circ + \angle N = 180^\circ$$
$$\angle N = 180^\circ - 110^\circ = 70^\circ$$
Since $\triangle LMN \sim \triangle PQR$, the corresponding angles are equal:
$$\angle L = \angle P,\quad \angle M = \angle Q,\quad \angle N = \angle R$$
Therefore:
$$\angle R = \angle N = 70^\circ$$
