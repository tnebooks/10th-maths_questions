## In an isosceles triangle $\triangle ABC$, with $\angle C = 90^\circ$ and $AC = 5\text{ cm}$, then $AB$ is

---

#### Since $\triangle ABC$ is an isosceles right triangle with $\angle C = 90^\circ$:
$$AC = BC = 5\text{ cm}$$

By Pythagoras theorem:
$$AB^2 = AC^2 + BC^2$$
$$AB^2 = 5^2 + 5^2 = 25 + 25 = 50$$
$$AB = \sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}\text{ cm}$$
