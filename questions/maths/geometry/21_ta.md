## இருசமபக்க முக்கோணம் $\triangle ABC$-யில் $\angle C = 90^\circ$ மற்றும் $AC = 5\text{ செ.மீ}$, எனில் $AB$ ஆனது

---

#### $\triangle ABC$ என்பது $\angle C = 90^\circ$ கொண்ட இருசமபக்க செங்கோண முக்கோணம் என்பதால்:
$$AC = BC = 5\text{ செ.மீ}$$

பித்தாகரஸ் தேற்றப்படி:
$$AB^2 = AC^2 + BC^2$$
$$AB^2 = 5^2 + 5^2 = 25 + 25 = 50$$
$$AB = \sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}\text{ செ.மீ}$$
