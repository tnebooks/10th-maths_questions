## பிதாகரஸ் தேற்றத்தை எழுதி நிரூபிக்க.

---

#### **கூற்று:**
ஒரு செங்கோண முக்கோணத்தில், கர்ணத்தின் வர்க்கம் மற்ற இரு பக்கங்களின் வர்க்கங்களின் கூடுதலுக்குச் சமம்.

#### **நிரூபணம்:**

**தரவு:** $\triangle ABC$-யில் $\angle A = 90^\circ$.

**நிரூபிக்க:** $AB^2 + AC^2 = BC^2$

**அமைப்பு:** $AD \perp BC$ வரைக.

| வ.எண் | கூற்று | காரணம் |
|:---:|:---|:---|
| 1 | $\triangle ABC \sim \triangle DBA$ | AA விதிமுறைப்படி |
| | $\dfrac{AB}{BD} = \dfrac{BC}{AB} \implies AB^2 = BC \times BD$ | ஒத்த பக்கங்கள் விகித சமம் $\quad \text{--- (1)}$ |
| 2 | $\triangle ABC \sim \triangle DAC$ | AA விதிமுறைப்படி |
| | $\dfrac{BC}{AC} = \dfrac{AC}{DC} \implies AC^2 = BC \times DC$ | ஒத்த பக்கங்கள் விகித சமம் $\quad \text{--- (2)}$ |
| 3 | $AB^2 + AC^2 = BC \times BD + BC \times DC$ | (1) மற்றும் (2)-ஐக் கூட்ட |
| | $= BC(BD + DC)$ | $BC$-ஐப் பொதுவாக எடுக்க |
| | $= BC \times BC = BC^2$ | $BD + DC = BC$ என்பதால் |
| 4 | $\mathbf{AB^2 + AC^2 = BC^2}$ | நிரூபிக்கப்பட்டது |

தேற்றம் நிரூபிக்கப்பட்டது.
