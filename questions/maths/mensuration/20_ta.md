## ஓர் உருளையின் மீது ஓர் இடைக்கண்டம் இணைந்தவாறு அமைந்த ஒரு புனலின் மொத்த உயரம் $20\text{ செ.மீ}$. உருளையின் உயரம் $12\text{ செ.மீ}$, விட்டம் $12\text{ செ.மீ}$ ஆகும். இடைக்கண்டத்தின் மேற்புற விட்டம் $24\text{ செ.மீ}$ எனில், புனலின் வெளிப்புறப் பரப்பைக் கணக்கிடுக.

---

#### விவரங்கள்:
- இடைக்கண்டத்தின் மேற்புற ஆரம் $R = \dfrac{24}{2} = 12\text{ செ.மீ}$
- உருளையின் ஆரம் (இடைக்கண்டத்தின் கீழ்ப்புற ஆரம்) $r = \dfrac{12}{2} = 6\text{ செ.மீ}$
- உருளையின் உயரம் $h_2 = 12\text{ செ.மீ}$
- புனலின் மொத்த உயரம் $= 20\text{ செ.மீ} \implies \text{இடைக்கண்டத்தின் உயரம் } h_1 = 20 - 12 = 8\text{ செ.மீ}$

**1. இடைக்கண்டத்தின் சாயுயரம் ($l$):**
$$l = \sqrt{(R - r)^2 + h_1^2} = \sqrt{(12 - 6)^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10\text{ செ.மீ}$$

**2. புனலின் வெளிப்புறப் பரப்பு:**
$$\text{வெளிப்புறப் பரப்பு} = \text{உருளையின் வளைபரப்பு} + \text{இடைக்கண்டத்தின் வளைபரப்பு}$$
$$= 2\pi r h_2 + \pi (R + r)l$$
$$= \pi [2r h_2 + (R + r)l]$$
$$= \pi [2(6)(12) + (12 + 6)(10)]$$
$$= \pi [144 + 180] = 324\pi$$
$$= \frac{22}{7} \times 324 \approx 1018.28\text{ செ.மீ}^2$$

**விடை:**
$$\mathbf{1018.28\text{ செ.மீ}^2}$$
