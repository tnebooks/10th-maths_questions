## ஓர் இறகு பந்தின் மேற்புறம் கூம்பின் இடைக்கண்ட வடிவிலும் கீழ்ப்புறம் அரைக்கோள வடிவிலும் உள்ளது. இடைக்கண்டத்தின் விட்டங்கள் $5\text{ செ.மீ}$ மற்றும் $2\text{ செ.மீ}$ ஆகவும், இறகுபந்தின் மொத்த உயரம் $7\text{ செ.மீ}$ ஆகவும் இருக்குமானால் இறகு பந்தின் புறப்பரப்பைக் காண்க.

---

#### இறகு பந்தானது இரண்டு திண்மங்களின் இணைப்பாக உள்ளது:
1. மேற்புறம்: கூம்பின் இடைக்கண்டம்
2. கீழ்ப்புறம்: அரைக்கோளம்

**படி 1: அளவுகளைக் குறிக்க.**
- இடைக்கண்டத்தின் கீழ்ப்புற விட்டம் = அரைக்கோளத்தின் விட்டம் = $2\text{ செ.மீ} \implies r = 1\text{ செ.மீ}$.
- அரைக்கோளத்தின் ஆரம் = $r = 1\text{ செ.மீ}$.
- அரைக்கோளத்தின் உயரம் = $r = 1\text{ செ.மீ}$.
- இடைக்கண்டத்தின் மேற்புற விட்டம் = $5\text{ செ.மீ} \implies R = 2.5\text{ செ.மீ}$.
- இறகு பந்தின் மொத்த உயரம் = $7\text{ செ.மீ}$.
- இடைக்கண்டத்தின் உயரம், $h = 7 - 1 = 6\text{ செ.மீ}$.

**படி 2: இடைக்கண்டத்தின் சாயுயரம் $l$-ஐக் காண்க.**
$$l = \sqrt{h^2 + (R - r)^2} = \sqrt{6^2 + (2.5 - 1)^2} = \sqrt{36 + 1.5^2} = \sqrt{36 + 2.25} = \sqrt{38.25} \approx 6.18\text{ செ.மீ}$$

**படி 3: புறப்பரப்பைக் கணக்கிடுக.**
$$\text{புறப்பரப்பு} = \text{இடைக்கண்டத்தின் வளைபரப்பு} + \text{அரைக்கோளத்தின் வளைபரப்பு}$$
$$\text{இடைக்கண்டத்தின் வளைபரப்பு} = \pi (R + r) l = \frac{22}{7} (2.5 + 1)(6.18) = \frac{22}{7} (3.5)(6.18) = 11 \times 6.18 = 67.98\text{ செ.மீ}^2$$
$$\text{அரைக்கோளத்தின் வளைபரப்பு} = 2\pi r^2 = 2 \times \frac{22}{7} \times 1^2 = \frac{44}{7} \approx 6.29\text{ செ.மீ}^2$$

$$\text{இறகு பந்தின் மொத்தப் புறப்பரப்பு} = 67.98 + 6.29 = 74.27\text{ செ.மீ}^2$$

**விடை:**
$$\mathbf{74.27\text{ செ.மீ}^2}$$
