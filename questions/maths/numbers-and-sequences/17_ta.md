## ஒரு கூட்டுத்தொடர்வரிசையின் 6வது உறுப்பின் 6 மடங்கும், 7வது உறுப்பின் 7 மடங்கும் சமம் எனில், அக்கூட்டுத் தொடர்வரிசையின் 13-வது உறுப்பு

---

#### முதல் உறுப்பு \(a\) என்றும், பொது வித்தியாசம் \(d\) என்றும் கொள்வோம். \(t_n = a + (n-1)d\) என்ற வாய்பாட்டின்படி:
\(t_6 = a + 5d\), \(t_7 = a + 6d\)

கொடுக்கப்பட்டவை: \(6 \, t_6 = 7 \, t_7\)
$$6(a + 5d) = 7(a + 6d)$$
$$6a + 30d = 7a + 42d$$
$$0 = a + 12d$$
$$a + 12d = 0$$
ஆனால் \(t_{13} = a + 12d\) (ஏனெனில் \(t_{13} = a + (13-1)d = a+12d\)). எனவே \(t_{13} = 0\) ஆகும்.
