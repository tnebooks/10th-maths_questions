## If $t_1, t_2, t_3, \ldots$ is an Arithmetic Progression, then $t_6, t_{12}, t_{18}, \ldots$ is

---

#### Since $t_1, t_2, t_3, \ldots$ is an A.P. with first term $a$ and common difference $d$, we have $t_n = a + (n-1)d$.
$$t_6 = a + 5d, \quad t_{12} = a + 11d, \quad t_{18} = a + 17d, \ldots$$
Check the difference between consecutive terms of this new sequence:
$$t_{12} - t_6 = (a+11d) - (a+5d) = 6d$$
$$t_{18} - t_{12} = (a+17d) - (a+11d) = 6d$$
Since the common difference is constant ($6d$), the sequence $t_6, t_{12}, t_{18}, \ldots$ is also an **Arithmetic Progression**.
