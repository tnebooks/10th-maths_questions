## \(S_1\), \(S_2\), மற்றும் \(S_3\) என்பன முறையே ஒரு கூட்டுத் தொடர்வரிசையின் முதல் \(n\), \(2n\) மற்றும் \(3n\) உறுப்புகளின் கூடுதல் ஆகும். \(S_3 = 3(S_2 - S_1)\) என நிறுவுக.

---

#### கூட்டுத்தொடர் வரிசையின் முதல் உறுப்பு \(a\) மற்றும் பொது வித்தியாசம் \(d\) எனக் கொள்வோம். முதல் \(k\) உறுப்புகளின் கூடுதலுக்கான வாய்பாடு \(S_k = \dfrac{k}{2}\big[2a + (k-1)d\big]\) பயன்படுத்துவோம்.

**படி 1: \(S_1\), \(S_2\), \(S_3\) ஐ எழுதுதல்**

$$S_1 = \frac{n}{2}\big[2a + (n-1)d\big]$$

$$S_2 = \frac{2n}{2}\big[2a + (2n-1)d\big] = n\big[2a + (2n-1)d\big]$$

$$S_3 = \frac{3n}{2}\big[2a + (3n-1)d\big]$$

**படி 2: \(S_2 - S_1\) காணுதல்**

$$S_2 - S_1 = n\big[2a + (2n-1)d\big] - \frac{n}{2}\big[2a + (n-1)d\big]$$

\(\dfrac{n}{2}\) ஐ பொதுவாக எடுக்க:

$$S_2 - S_1 = \frac{n}{2}\Big\{2\big[2a + (2n-1)d\big] - \big[2a + (n-1)d\big]\Big\}$$

$$= \frac{n}{2}\Big\{4a + 2(2n-1)d - 2a - (n-1)d\Big\}$$

$$= \frac{n}{2}\Big\{2a + \big[2(2n-1) - (n-1)\big]d\Big\}$$

$$= \frac{n}{2}\Big\{2a + \big[4n - 2 - n + 1\big]d\Big\}$$

$$= \frac{n}{2}\big[2a + (3n-1)d\big]$$

**படி 3: \(3\) ஆல் பெருக்கி \(S_3\) உடன் ஒப்பிடுதல்**

$$3(S_2 - S_1) = 3 \times \frac{n}{2}\big[2a + (3n-1)d\big] = \frac{3n}{2}\big[2a + (3n-1)d\big]$$

இது படி 1 இல் கணக்கிட்ட \(S_3\) க்குச் சமமாகும்.

**சரிபார்ப்பு (எண்ணியல் சோதனை \(a=2\), \(d=3\), \(n=4\) உடன்):** \(S_1 = S_4 = 26\), \(S_2 = S_8 = 100\), \(S_3 = S_{12} = 222\). சரிபார்க்க: \(3(S_2-S_1) = 3(100-26) = 3(74) = 222 = S_3\). ✓

**விடை:**
$$\mathbf{S_3 = 3(S_2 - S_1) \text{ — நிறுவப்பட்டது}}$$
