## Find the sum of all odd positive integers less than $450$.

---

#### The odd positive integers less than $450$ form an Arithmetic Progression: $1, 3, 5, \ldots, 449$. Identify the first term, common difference, and last term, find the number of terms, then apply the sum formula.

**Step 1: Identify the A.P.**

First term $a = 1$, common difference $d = 2$, last term $l = 449$ (the largest odd number below $450$).

**Step 2: Find the number of terms $n$**

Using $l = a + (n-1)d$:
$$449 = 1 + (n-1)(2)$$
$$448 = 2(n-1)$$
$$n - 1 = 224$$
$$n = 225$$

**Step 3: Apply the sum formula**

$$S_n = \frac{n}{2}(a + l)$$

$$S_{225} = \frac{225}{2}(1 + 449) = \frac{225}{2}(450) = 225 \times 225$$

$$S_{225} = 50625$$

**Verification (small-scale check):** Sum of odd integers less than $10$ (i.e. $1,3,5,7,9$): using the same method, $n = \dfrac{(9-1)}{2}+1 = 5$, $S_5 = \dfrac{5}{2}(1+9) = 25$. Direct addition: $1+3+5+7+9 = 25$. ✓ Also note the known identity that the sum of the first $n$ odd numbers is $n^2$; here $n = 225$, so $S = 225^2 = 50625$, matching. ✓

**Answer:**
$$\mathbf{50625}$$
