## If $S_n = (x + y) + (x^2 + xy + y^2) + (x^3 + x^2y + xy^2 + y^3) + \dots 	ext{ to } n 	ext{ terms}$, prove that:
$$(x - y)S_n = rac{x^2(x^n - 1)}{x - 1} - rac{y^2(y^n - 1)}{y - 1}$$

---

#### Multiplying both sides of the sum $S_n$ by $(x - y)$:
$$(x - y)S_n = (x - y)(x + y) + (x - y)(x^2 + xy + y^2) + (x - y)(x^3 + x^2y + xy^2 + y^3) + \dots 	ext{ to } n 	ext{ terms}$$

Using the algebraic identities:
- $(x - y)(x + y) = x^2 - y^2$
- $(x - y)(x^2 + xy + y^2) = x^3 - y^3$
- $(x - y)(x^3 + x^2y + xy^2 + y^3) = x^4 - y^4$

In general, the $k$-th term becomes $(x^{k+1} - y^{k+1})$.

Thus:
$$(x - y)S_n = (x^2 - y^2) + (x^3 - y^3) + (x^4 - y^4) + \dots + (x^{n+1} - y^{n+1})$$

Rearranging the terms of $x$ and $y$ separately:
$$(x - y)S_n = (x^2 + x^3 + x^4 + \dots + x^{n+1}) - (y^2 + y^3 + y^4 + \dots + y^{n+1})$$

Both bracketed expressions are geometric progressions of $n$ terms:
1. For the first G.P., the first term is $a = x^2$ and the common ratio is $r = x$:
   $$	ext{Sum} = rac{x^2(x^n - 1)}{x - 1}$$

2. For the second G.P., the first term is $a = y^2$ and the common ratio is $r = y$:
   $$	ext{Sum} = rac{y^2(y^n - 1)}{y - 1}$$

Substituting these sums:
$$(x - y)S_n = rac{x^2(x^n - 1)}{x - 1} - rac{y^2(y^n - 1)}{y - 1}$$

Hence proved.
