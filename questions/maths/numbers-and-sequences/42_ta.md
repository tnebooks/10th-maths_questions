## $S_n = (x + y) + (x^2 + xy + y^2) + (x^3 + x^2y + xy^2 + y^3) + \dots n   ext{ உறுப்புகள் வரை}$ எனில்,
$$(x - y)S_n = \frac{x^2(x^n - 1)}{x - 1} - \frac{y^2(y^n - 1)}{y - 1}   ext{ என நிறுவுக.}$$

---

#### கொடுக்கப்பட்ட தொடரின் இருபுறமும் $(x - y)$-ஆல் பெருக்க:
$$(x - y)S_n = (x - y)(x + y) + (x - y)(x^2 + xy + y^2) + (x - y)(x^3 + x^2y + xy^2 + y^3) + \dots n   ext{ உறுப்புகள் வரை}$$

இயற்கணித முற்றொருமைகளைப் பயன்படுத்த:
- $(x - y)(x + y) = x^2 - y^2$
- $(x - y)(x^2 + xy + y^2) = x^3 - y^3$
- $(x - y)(x^3 + x^2y + xy^2 + y^3) = x^4 - y^4$

எனவே:
$$(x - y)S_n = (x^2 - y^2) + (x^3 - y^3) + (x^4 - y^4) + \dots + (x^{n+1} - y^{n+1})$$

$x$ மற்றும் $y$ உறுப்புகளைத் தனித்தனியாகப் பிரிக்க:
$$(x - y)S_n = (x^2 + x^3 + x^4 + \dots + x^{n+1}) - (y^2 + y^3 + y^4 + \dots + y^{n+1})$$

இவ்விரு அடைப்புக் குறிகளிலுள்ள தொடர்களும் $n$ உறுப்புகளைக் கொண்ட பெருக்குத் தொடர்வரிசைகளாகும்:
1. முதல் பெருக்குத் தொடரில் முதல் உறுப்பு $a = x^2$, பொது விகிதம் $r = x$:
   $$  ext{கூடுதல்} = \frac{x^2(x^n - 1)}{x - 1}$$

2. இரண்டாவது பெருக்குத் தொடரில் முதல் உறுப்பு $a = y^2$, பொது விகிதம் $r = y$:
   $$  ext{கூடுதல்} = \frac{y^2(y^n - 1)}{y - 1}$$

இம்மதிப்புகளைப் பிரதியிட:
$$(x - y)S_n = \frac{x^2(x^n - 1)}{x - 1} - \frac{y^2(y^n - 1)}{y - 1}$$

எனவே நிறுவப்பட்டது.
