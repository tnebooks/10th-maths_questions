## (i) Find the least positive value of $x$ such that $67 + x \equiv 1 \pmod 4$.
## (ii) Solve $5x \equiv 4 \pmod 6$.

---

#### **Part (i): Find least positive $x$ such that $67 + x \equiv 1 \pmod 4$**

By definition of modular congruence:
$$67 + x - 1 = 4k \quad \text{for some integer } k$$
$$66 + x = 4k$$

This means $66 + x$ must be a positive multiple of $4$.
The positive multiples of $4$ greater than $66$ are $68, 72, 76, \dots$

For the least positive value of $x$:
$$66 + x = 68 \implies x = 68 - 66 = 2$$

Thus, the least positive value is $x = 2$.

---

#### **Part (ii): Solve $5x \equiv 4 \pmod 6$**

By definition of congruence:
$$5x - 4 = 6k \quad \text{for some integer } k$$
$$5x = 6k + 4 \implies x = \frac{6k + 4}{5}$$

Since $x$ must be an integer, $6k + 4$ must be a multiple of $5$:
- For $k = 1$: $6(1) + 4 = 10 \implies x = \frac{10}{5} = 2$
- For $k = 6$: $6(6) + 4 = 40 \implies x = \frac{40}{5} = 8$
- For $k = 11$: $6(11) + 4 = 70 \implies x = \frac{70}{5} = 14$

In general, the solution is:
$$x = 2, 8, 14, 20, \dots \quad (x \equiv 2 \pmod 6)$$

**Answer:**
$$\mathbf{(i)\ x = 2, \qquad (ii)\ x = 2, 8, 14, \dots}$$
