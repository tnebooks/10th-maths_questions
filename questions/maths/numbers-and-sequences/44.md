## The houses of a street are numbered from $1$ to $49$. Senthil's house is numbered such that the sum of numbers of the houses prior to Senthil's house is equal to the sum of numbers of the houses following Senthil's house. Find Senthil's house number.

---

#### Let Senthil's house number be $x$, where $1 < x < 49$.

- The house numbers preceding Senthil's house are $1, 2, 3, \dots, (x - 1)$.
- The house numbers following Senthil's house are $(x + 1), (x + 2), \dots, 49$.

According to the given condition:
$$1 + 2 + 3 + \dots + (x - 1) = (x + 1) + (x + 2) + \dots + 49$$

The sum of house numbers from $(x + 1)$ to $49$ can be written as:
$$(x + 1) + (x + 2) + \dots + 49 = (1 + 2 + \dots + 49) - (1 + 2 + \dots + x)$$

Therefore:
$$(1 + 2 + \dots + (x - 1)) = (1 + 2 + \dots + 49) - (1 + 2 + \dots + x)$$
$$(1 + 2 + \dots + (x - 1)) + (1 + 2 + \dots + x) = 1 + 2 + \dots + 49$$

Using the formula for the sum of first $n$ natural numbers, $\sum_{i=1}^n i = \frac{n(n+1)}{2}$:
$$\frac{(x - 1)x}{2} + \frac{x(x + 1)}{2} = \frac{49 \times 50}{2}$$

Multiplying both sides by $2$:
$$x(x - 1) + x(x + 1) = 49 \times 50$$
$$x^2 - x + x^2 + x = 2450$$
$$2x^2 = 2450$$
$$x^2 = 1225$$
$$x = \sqrt{1225} = 35$$

Since house numbers are positive integers, $x = 35$.

**Verification:**
- Sum before house 35: $1 + 2 + \dots + 34 = \frac{34 \times 35}{2} = 595$
- Sum after house 35: $36 + 37 + \dots + 49 = \frac{49 \times 50}{2} - \frac{35 \times 36}{2} = 1225 - 630 = 595$ ✓

**Answer:**
$$\mathbf{35}$$
