## ஒரு தெருவிலுள்ள வீடுகளுக்கு $1$ முதல் $49$ வரை தொடர்ச்சியாகக் கதவிலக்கம் வழங்கப்பட்டுள்ளது. செந்திலின் வீட்டிற்கு முன்னதாக உள்ள வீடுகளின் கதவிலக்கங்களின் கூட்டுத்தொகையானது செந்திலின் வீட்டிற்குப் பின்னதாக உள்ள வீடுகளின் கதவிலக்கங்களின் கூட்டுத் தொகைக்குச் சமம் எனில் செந்திலின் வீட்டுக் கதவிலக்கத்தைக் காண்க.

#### செந்திலின் வீட்டின் கதவிலக்கம் $x$ என்க ($1 < x < 49$).

- செந்திலின் வீட்டிற்கு முன் உள்ள வீடுகளின் கதவிலக்கங்கள்: $1, 2, 3, \dots, (x - 1)$.
- செந்திலின் வீட்டிற்குப் பின் உள்ள வீடுகளின் கதவிலக்கங்கள்: $(x + 1), (x + 2), \dots, 49$.

கொடுக்கப்பட்ட நிபந்தனையின்படி:
$$1 + 2 + 3 + \dots + (x - 1) = (x + 1) + (x + 2) + \dots + 49$$

$(x + 1)$ முதல் $49$ வரையிலான கூடுதல்:
$$(x + 1) + (x + 2) + \dots + 49 = (1 + 2 + \dots + 49) - (1 + 2 + \dots + x)$$

எனவே:
$$(1 + 2 + \dots + (x - 1)) = (1 + 2 + \dots + 49) - (1 + 2 + \dots + x)$$
$$(1 + 2 + \dots + (x - 1)) + (1 + 2 + \dots + x) = 1 + 2 + \dots + 49$$

முதல் $n$ இயல் எண்களின் கூடுதல் சூத்திரம் $\sum_{i=1}^n i = \frac{n(n+1)}{2}$-ஐப் பயன்படுத்த:
$$\frac{(x - 1)x}{2} + \frac{x(x + 1)}{2} = \frac{49 \times 50}{2}$$

இருபுறமும் $2$-ஆல் பெருக்க:
$$x(x - 1) + x(x + 1) = 49 \times 50$$
$$x^2 - x + x^2 + x = 2450$$
$$2x^2 = 2450$$
$$x^2 = 1225$$
$$x = \sqrt{1225} = 35$$

கதவிலக்கம் ஒரு மிகை முழு எண் என்பதால், $x = 35$ ஆகும்.

**சரிபார்த்தல்:**
- கதவிலக்கம் $35$-க்கு முன் உள்ள கூடுதல்: $1 + 2 + \dots + 34 = \frac{34 \times 35}{2} = 595$
- கதவிலக்கம் $35$-க்கு பின் உள்ள கூடுதல்: $36 + \dots + 49 = \frac{49 \times 50}{2} - \frac{35 \times 36}{2} = 1225 - 630 = 595$ ✓

**விடை:**
$$\mathbf{35}$$
