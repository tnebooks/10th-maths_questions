## If $f:A\to B$ is a bijective function and $n(B) = 7$, then $n(A)$ is

---

#### A bijective function is both one-to-one (injective) and onto (surjective). For a bijection to exist between two finite sets $A$ and $B$, the two sets must have exactly the same number of elements, that is $n(A) = n(B)$. Given $n(B) = 7$, it follows that $n(A) = 7$.
