## $A$ is the set of all natural numbers less than 8, $B$ is the set of all prime numbers less than 8, and $C$ is the set of even prime numbers. Verify that $(A \cap B) \times C = (A \times C) \cap (B \times C)$

---

#### Writing each set in roster form:

Since $\mathbb{N} = \{1, 2, 3, 4, \ldots\}$, the natural numbers less than 8 are:
$$A = \{1, 2, 3, 4, 5, 6, 7\}$$

The prime numbers less than 8 are:
$$B = \{2, 3, 5, 7\}$$

The only even prime number is 2, so:
$$C = \{2\}$$

**Left Hand Side (LHS): $(A \cap B) \times C$**

First find $A \cap B$. Since every element of $B$ is also in $A$ ($B \subseteq A$):
$$A \cap B = \{2, 3, 5, 7\}$$

Now compute the Cartesian product with $C$:
$$(A \cap B) \times C = \{2, 3, 5, 7\} \times \{2\}$$
$$\text{LHS} = \{(2, 2), (3, 2), (5, 2), (7, 2)\} \quad \text{--- (1)}$$

**Right Hand Side (RHS): $(A \times C) \cap (B \times C)$**

$$A \times C = \{1, 2, 3, 4, 5, 6, 7\} \times \{2\} = \{(1,2), (2,2), (3,2), (4,2), (5,2), (6,2), (7,2)\}$$
$$B \times C = \{2, 3, 5, 7\} \times \{2\} = \{(2,2), (3,2), (5,2), (7,2)\}$$

Taking the intersection (keeping only ordered pairs common to both sets):
$$(A \times C) \cap (B \times C) = \{(2, 2), (3, 2), (5, 2), (7, 2)\} \quad \text{--- (2)}$$

**Conclusion**

From (1) and (2):
$$\text{LHS} = \{(2, 2), (3, 2), (5, 2), (7, 2)\} = \text{RHS}$$

This illustrates the general distributive property of the Cartesian product over set intersection: $(A \cap B) \times C = (A \times C) \cap (B \times C)$.

**Answer:**
$$\mathbf{(A \cap B) \times C = (A \times C) \cap (B \times C) = \{(2, 2), (3, 2), (5, 2), (7, 2)\} \text{ — verified}}$$
