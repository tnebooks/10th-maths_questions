## $A$ என்பது 8-ஐ விடக் குறைவான இயல் எண்களின் கணம், $B$ என்பது 8-ஐ விடக் குறைவான பகா எண்களின் கணம் மற்றும் $C$ என்பது இரட்டைப்படை பகா எண்களின் கணம் எனில் $(A \cap B) \times C = (A \times C) \cap (B \times C)$ என்பதை சரிபார்க்க

---

#### ஒவ்வொரு கணத்தையும் பட்டியல் முறையில் எழுதுதல்:

$\mathbb{N} = \{1, 2, 3, 4, \ldots\}$ என்பதால், 8-ஐ விடக் குறைவான இயல் எண்கள்:
$$A = \{1, 2, 3, 4, 5, 6, 7\}$$

8-ஐ விடக் குறைவான பகா எண்கள்:
$$B = \{2, 3, 5, 7\}$$

இரட்டைப்படை பகா எண் ஒன்று மட்டுமே உள்ளது, அது 2. எனவே:
$$C = \{2\}$$

**இடதுபக்கம் (LHS): $(A \cap B) \times C$**

முதலில் $A \cap B$-ஐக் காண்போம். $B$-ன் ஒவ்வொரு உறுப்பும் $A$-ல் உள்ளது ($B \subseteq A$) என்பதால்:
$$A \cap B = \{2, 3, 5, 7\}$$

இப்போது $C$-உடன் கார்ட்டீசியன் பெருக்கலைக் காண்போம்:
$$(A \cap B) \times C = \{2, 3, 5, 7\} \times \{2\}$$
$$\text{LHS} = \{(2, 2), (3, 2), (5, 2), (7, 2)\} \quad \text{--- (1)}$$

**வலதுபக்கம் (RHS): $(A \times C) \cap (B \times C)$**

$$A \times C = \{1, 2, 3, 4, 5, 6, 7\} \times \{2\} = \{(1,2), (2,2), (3,2), (4,2), (5,2), (6,2), (7,2)\}$$
$$B \times C = \{2, 3, 5, 7\} \times \{2\} = \{(2,2), (3,2), (5,2), (7,2)\}$$

இரண்டு கணங்களுக்கும் பொதுவான வரிசைச் சோடிகளை மட்டும் எடுத்துக்கொண்டு வெட்டுத்தொகுப்பு காணுதல்:
$$(A \times C) \cap (B \times C) = \{(2, 2), (3, 2), (5, 2), (7, 2)\} \quad \text{--- (2)}$$

**முடிவு**

(1) மற்றும் (2)-லிருந்து:
$$\text{LHS} = \{(2, 2), (3, 2), (5, 2), (7, 2)\} = \text{RHS}$$

இது கார்ட்டீசியன் பெருக்கல் வெட்டுத்தொகுப்பின் மீது பங்கீட்டுப் பண்பைக் (distributive property) கொண்டிருப்பதைக் காட்டுகிறது: $(A \cap B) \times C = (A \times C) \cap (B \times C)$.

**விடை:**
$$\mathbf{(A \cap B) \times C = (A \times C) \cap (B \times C) = \{(2, 2), (3, 2), (5, 2), (7, 2)\} \text{ — சரிபார்க்கப்பட்டது}}$$
