## If the number of relations from $A = \{1,2,3,4,5\}$ to a set $B$ is 1024, then the number of elements in $B$ is

---

#### The number of relations from a set $A$ to a set $B$ is $2^{n(A) \times n(B)}$. Here $n(A) = 5$ and the number of relations is given as $1024$. So $2^{5 \times n(B)} = 1024$. Since $1024 = 2^{10}$, we equate the exponents: $5 \times n(B) = 10 \implies n(B) = \frac{10}{5} = 2$.
