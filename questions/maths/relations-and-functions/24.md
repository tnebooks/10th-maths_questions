## If $f(x) = (-1)^x$ is defined from $\mathbb{N}$ to $\mathbb{Z}$, then the range of $f$ is

---

#### Given function $f: \mathbb{N} \to \mathbb{Z}$ defined by $f(x) = (-1)^x$.

For domain values $x \in \mathbb{N} = \{1, 2, 3, 4, \dots\}$:
- For odd natural numbers ($x = 1, 3, 5, \dots$):
  $$f(x) = (-1)^x = -1$$
- For even natural numbers ($x = 2, 4, 6, \dots$):
  $$f(x) = (-1)^x = 1$$

Thus, the set of all outputs (the range of $f$) is:
$$\text{Range} = \{1, -1\}$$
