## If $f : A \to B$ is a bijective function and $n(B) = 7$, then $n(A)$ is

---

#### A bijective (one-one and onto) function requires both sets to be in a perfect one-to-one correspondence with no element left unmapped on either side. This is only possible when the two sets have exactly the same number of elements. Therefore $n(A) = n(B) = 7$.
