## If $\{(a,8), (6,b)\}$ is an identity function, then the values of $a$ and $b$ are respectively

---

#### An identity function maps every element to itself, that is, every ordered pair must be of the form $(x,x)$. For the pair $(a,8)$ to be of this form, we need $a = 8$. For the pair $(6,b)$ to be of this form, we need $b = 6$. Therefore $a = 8$ and $b = 6$, giving the pair of values $(8,6)$.
