## A function $f : [-5, 9] \to \mathbb{R}$ is defined as follows: $f(x) = 6x+1$ for $-5 \le x < 2$; $5x^2-1$ for $2 \le x < 6$; $3x-4$ for $6 \le x \le 9$. Find: (i) $f(-3) + f(2)$ (ii) $f(7) - f(1)$ (iii) $2f(4) + f(8)$

---

#### Given the piecewise function:
$$f(x) = \begin{cases} 6x + 1, & -5 \le x < 2 \\ 5x^2 - 1, & 2 \le x < 6 \\ 3x - 4, & 6 \le x \le 9 \end{cases}$$

**(i) Finding $f(-3) + f(2)$:**

Since $-5 \le -3 < 2$, use $f(x) = 6x + 1$:
$$f(-3) = 6(-3) + 1 = -18 + 1 = -17$$

Since $2 \le 2 < 6$, use $f(x) = 5x^2 - 1$:
$$f(2) = 5(2)^2 - 1 = 5(4) - 1 = 20 - 1 = 19$$

$$f(-3) + f(2) = -17 + 19 = \mathbf{2}$$

**(ii) Finding $f(7) - f(1)$:**

Since $6 \le 7 \le 9$, use $f(x) = 3x - 4$:
$$f(7) = 3(7) - 4 = 21 - 4 = 17$$

Since $-5 \le 1 < 2$, use $f(x) = 6x + 1$:
$$f(1) = 6(1) + 1 = 7$$

$$f(7) - f(1) = 17 - 7 = \mathbf{10}$$

**(iii) Finding $2f(4) + f(8)$:**

Since $2 \le 4 < 6$, use $f(x) = 5x^2 - 1$:
$$f(4) = 5(4)^2 - 1 = 5(16) - 1 = 80 - 1 = 79$$

Since $6 \le 8 \le 9$, use $f(x) = 3x - 4$:
$$f(8) = 3(8) - 4 = 24 - 4 = 20$$

$$2f(4) + f(8) = 2(79) + 20 = 158 + 20 = \mathbf{178}$$

**Answer:**
$$\mathbf{(i)\ 2 \qquad (ii)\ 10 \qquad (iii)\ 178}$$
