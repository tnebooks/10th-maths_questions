## If $f: A \to B$ is a bijective function and if $n(B) = 7$, then $n(A)$ is equal to

---

#### A bijective function is both one-one (injective) and onto (surjective). A one-one function requires distinct elements of $A$ to map to distinct elements of $B$, and an onto function requires every element of $B$ to be the image of some element of $A$.

For such a correspondence to exist between finite sets $A$ and $B$, the two sets must have the same number of elements, since the function sets up a perfect pairing between the elements of $A$ and the elements of $B$:
$$n(A) = n(B)$$

Given $n(B) = 7$:
$$n(A) = 7$$

**Answer: $7$**
