## Which of the following represents a constant function?

---

#### A constant function is a function that assigns the same output value to every input in its domain, regardless of what that input is. That is, its rule has the form $f(x) = c$ for some fixed constant $c$, so the value of $f(x)$ never changes as $x$ varies. Among the given forms, $f(x) = x$ is the identity function, $f(x) = mx + c$ is a linear function (when $m \neq 0$), and $f(x) = \dfrac{1}{x}$ is a reciprocal function — none of these keep $f(x)$ fixed as $x$ changes. Only $f(x) = c$ outputs the same value for every $x$.

**Answer:**
$$\mathbf{f(x) = c}$$
