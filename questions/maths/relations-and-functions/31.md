## If $A = \{x \in W \mid x < 2\}$, $B = \{x \in \mathbb{N} \mid 1 < x \le 4\}$ and $C = \{3,5\}$, then verify that $(A \cup B) \times C = (A \times C) \cup (B \times C)$.

---

#### Given: $A = \{x \in W \mid x < 2\}$, where $W$ is the set of whole numbers $\{0, 1, 2, 3, \ldots\}$. So:
$$A = \{0, 1\}$$

$B = \{x \in \mathbb{N} \mid 1 < x \le 4\}$, where $\mathbb{N}$ is the set of natural numbers. So:
$$B = \{2, 3, 4\}$$

$$C = \{3, 5\}$$

**Step 1: Find $A \cup B$.**
$$A \cup B = \{0, 1\} \cup \{2, 3, 4\} = \{0, 1, 2, 3, 4\}$$

**Step 2: Find $(A \cup B) \times C$ — the LHS.**
$$(A \cup B) \times C = \{0, 1, 2, 3, 4\} \times \{3, 5\}$$
$$= \{(0,3), (0,5), (1,3), (1,5), (2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$

**Step 3: Find $A \times C$.**
$$A \times C = \{0, 1\} \times \{3, 5\} = \{(0,3), (0,5), (1,3), (1,5)\}$$

**Step 4: Find $B \times C$.**
$$B \times C = \{2, 3, 4\} \times \{3, 5\} = \{(2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$

**Step 5: Find $(A \times C) \cup (B \times C)$ — the RHS.**
$$(A \times C) \cup (B \times C) = \{(0,3), (0,5), (1,3), (1,5)\} \cup \{(2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$
$$= \{(0,3), (0,5), (1,3), (1,5), (2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$

**Step 6: Compare LHS and RHS.**

Both the LHS (Step 2) and the RHS (Step 5) give the exact same set of ten ordered pairs. Therefore:
$$\mathbf{(A \cup B) \times C = (A \times C) \cup (B \times C) \ \text{is verified.}}$$
