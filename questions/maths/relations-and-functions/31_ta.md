## $A = \{x \in W \mid x < 2\}$, $B = \{x \in \mathbb{N} \mid 1 < x \le 4\}$ மற்றும் $C = \{3,5\}$ எனில், $(A \cup B) \times C = (A \times C) \cup (B \times C)$ என்ற சமன்பாட்டினைச் சரிபார்.

---

#### கொடுக்கப்பட்டவை: $A = \{x \in W \mid x < 2\}$, இங்கு $W$ முழு எண்களின் கணம் $\{0, 1, 2, 3, \ldots\}$. எனவே:
$$A = \{0, 1\}$$

$B = \{x \in \mathbb{N} \mid 1 < x \le 4\}$, இங்கு $\mathbb{N}$ இயல் எண்களின் கணம். எனவே:
$$B = \{2, 3, 4\}$$

$$C = \{3, 5\}$$

**படி 1: $A \cup B$ ஐக் காணுதல்.**
$$A \cup B = \{0, 1\} \cup \{2, 3, 4\} = \{0, 1, 2, 3, 4\}$$

**படி 2: $(A \cup B) \times C$ ஐக் காணுதல் — இடப்புறம் (LHS).**
$$(A \cup B) \times C = \{0, 1, 2, 3, 4\} \times \{3, 5\}$$
$$= \{(0,3), (0,5), (1,3), (1,5), (2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$

**படி 3: $A \times C$ ஐக் காணுதல்.**
$$A \times C = \{0, 1\} \times \{3, 5\} = \{(0,3), (0,5), (1,3), (1,5)\}$$

**படி 4: $B \times C$ ஐக் காணுதல்.**
$$B \times C = \{2, 3, 4\} \times \{3, 5\} = \{(2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$

**படி 5: $(A \times C) \cup (B \times C)$ ஐக் காணுதல் — வலப்புறம் (RHS).**
$$(A \times C) \cup (B \times C) = \{(0,3), (0,5), (1,3), (1,5)\} \cup \{(2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$
$$= \{(0,3), (0,5), (1,3), (1,5), (2,3), (2,5), (3,3), (3,5), (4,3), (4,5)\}$$

**படி 6: இடப்புறத்தையும் வலப்புறத்தையும் ஒப்பிடுதல்.**

இடப்புறம் (படி 2) மற்றும் வலப்புறம் (படி 5) இரண்டும் ஒரே பத்து வரிசைச் சோடிகளின் கணமாக உள்ளன. எனவே:
$$\mathbf{(A \cup B) \times C = (A \times C) \cup (B \times C) \ \text{சரிபார்க்கப்பட்டது.}}$$
