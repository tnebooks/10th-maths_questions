## Given $A = \{x \in \mathbb{N} \mid 1 < x < 4\}$, $B = \{x \in \mathbb{W} \mid 0 \le x < 2\}$ and $C = \{x \in \mathbb{N} \mid x < 3\}$, verify that $A \times (B \cap C) = (A \times B) \cap (A \times C)$.

---

#### Given $A = \{x \in \mathbb{N} \mid 1 < x < 4\}$, $B = \{x \in \mathbb{W} \mid 0 \le x < 2\}$, $C = \{x \in \mathbb{N} \mid x < 3\}$.

**Step 1: Write out the sets.**
Since $\mathbb{N} = \{1,2,3,\ldots\}$ and $\mathbb{W} = \{0,1,2,\ldots\}$:
$$A = \{2, 3\}, \quad B = \{0, 1\}, \quad C = \{1, 2\}$$

**Step 2: Find $B \cap C$.**
$$B \cap C = \{0,1\} \cap \{1,2\} = \{1\}$$

**Step 3: Find $A \times (B \cap C)$.**
$$A \times (B \cap C) = \{2,3\} \times \{1\} = \{(2,1), (3,1)\}$$

**Step 4: Find $A \times B$.**
$$A \times B = \{2,3\} \times \{0,1\} = \{(2,0), (2,1), (3,0), (3,1)\}$$

**Step 5: Find $A \times C$.**
$$A \times C = \{2,3\} \times \{1,2\} = \{(2,1), (2,2), (3,1), (3,2)\}$$

**Step 6: Find $(A \times B) \cap (A \times C)$.**
$$(A \times B) \cap (A \times C) = \{(2,0), (2,1), (3,0), (3,1)\} \cap \{(2,1), (2,2), (3,1), (3,2)\} = \{(2,1), (3,1)\}$$

**Step 7: Compare.**
From Step 3: $A \times (B \cap C) = \{(2,1), (3,1)\}$.
From Step 6: $(A \times B) \cap (A \times C) = \{(2,1), (3,1)\}$.

Since both sides are equal, we have verified:
$$\mathbf{A \times (B \cap C) = (A \times B) \cap (A \times C) = \{(2,1), (3,1)\}}$$
