## $A = \{x \in \mathbb{N} \mid 1 < x < 4\}$, $B = \{x \in \mathbb{W} \mid 0 \le x < 2\}$ மற்றும் $C = \{x \in \mathbb{N} \mid x < 3\}$ எனில் $A \times (B \cap C) = (A \times B) \cap (A \times C)$ என்பதைச் சரிபார்.

---

#### கொடுக்கப்பட்டவை: $A = \{x \in \mathbb{N} \mid 1 < x < 4\}$, $B = \{x \in \mathbb{W} \mid 0 \le x < 2\}$, $C = \{x \in \mathbb{N} \mid x < 3\}$.

**படி 1: கணங்களை எழுதுதல்.**
$\mathbb{N} = \{1,2,3,\ldots\}$ மற்றும் $\mathbb{W} = \{0,1,2,\ldots\}$ என்பதால்:
$$A = \{2, 3\}, \quad B = \{0, 1\}, \quad C = \{1, 2\}$$

**படி 2: $B \cap C$ ஐக் காணுதல்.**
$$B \cap C = \{0,1\} \cap \{1,2\} = \{1\}$$

**படி 3: $A \times (B \cap C)$ ஐக் காணுதல்.**
$$A \times (B \cap C) = \{2,3\} \times \{1\} = \{(2,1), (3,1)\}$$

**படி 4: $A \times B$ ஐக் காணுதல்.**
$$A \times B = \{2,3\} \times \{0,1\} = \{(2,0), (2,1), (3,0), (3,1)\}$$

**படி 5: $A \times C$ ஐக் காணுதல்.**
$$A \times C = \{2,3\} \times \{1,2\} = \{(2,1), (2,2), (3,1), (3,2)\}$$

**படி 6: $(A \times B) \cap (A \times C)$ ஐக் காணுதல்.**
$$(A \times B) \cap (A \times C) = \{(2,0), (2,1), (3,0), (3,1)\} \cap \{(2,1), (2,2), (3,1), (3,2)\} = \{(2,1), (3,1)\}$$

**படி 7: ஒப்பிடுதல்.**
படி 3-லிருந்து: $A \times (B \cap C) = \{(2,1), (3,1)\}$.
படி 6-லிருந்து: $(A \times B) \cap (A \times C) = \{(2,1), (3,1)\}$.

இரு பக்கங்களும் சமமாக இருப்பதால், சரிபார்க்கப்படுகிறது:
$$\mathbf{A \times (B \cap C) = (A \times B) \cap (A \times C) = \{(2,1), (3,1)\}}$$
