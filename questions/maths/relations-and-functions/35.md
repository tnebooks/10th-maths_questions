## A function $f$ is defined by $f(x) = \begin{cases} x+2 & ; & x > 1 \\ 2 & ; & -1 \le x \le 1 \\ x-1 & ; & -3 < x < -1 \end{cases}$. Find the values of: (i) $f(3)$ (ii) $f(0)$ (iii) $f(-1.5)$ (iv) $f(2) + f(-2)$

---

#### Given $f(x) = \begin{cases} x+2 & ; & x > 1 \\ 2 & ; & -1 \le x \le 1 \\ x-1 & ; & -3 < x < -1 \end{cases}$

**(i) $f(3)$:**
Since $3 > 1$, use $f(x) = x + 2$:
$$f(3) = 3 + 2 = \mathbf{5}$$

**(ii) $f(0)$:**
Since $-1 \le 0 \le 1$, use $f(x) = 2$:
$$f(0) = \mathbf{2}$$

**(iii) $f(-1.5)$:**
Since $-3 < -1.5 < -1$, use $f(x) = x - 1$:
$$f(-1.5) = -1.5 - 1 = \mathbf{-2.5}$$

**(iv) $f(2) + f(-2)$:**
For $f(2)$: since $2 > 1$, use $f(x) = x + 2$:
$$f(2) = 2 + 2 = 4$$
For $f(-2)$: since $-3 < -2 < -1$, use $f(x) = x - 1$:
$$f(-2) = -2 - 1 = -3$$
Adding:
$$f(2) + f(-2) = 4 + (-3) = \mathbf{1}$$

**Answer:**
$$\mathbf{f(3) = 5,\ f(0) = 2,\ f(-1.5) = -2.5,\ f(2)+f(-2) = 1}$$
