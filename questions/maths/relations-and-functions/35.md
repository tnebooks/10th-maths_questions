## If $A = \{a, b, p\}$, $B = \{2, 3\}$, $C = \{p, q, r, s\}$, then $n[(A \cup C) \times B]$ is

---

#### Given sets:
$$A = \{a, b, p\}, \quad C = \{p, q, r, s\}$$

Find the union $A \cup C$:
$$A \cup C = \{a, b, p, q, r, s\} \implies n(A \cup C) = 6$$

Given $B = \{2, 3\}$, the number of elements is:
$$n(B) = 2$$

Therefore, the number of elements in $(A \cup C) \times B$ is:
$$n[(A \cup C) \times B] = n(A \cup C) \times n(B) = 6 \times 2 = 12$$
