## If $A = \{1, 2, 3, 4\}$, $B = \{4, 8, 9, 10\}$ and $f: A \to B$ is given by $f = \{(1, 4), (2, 8), (3, 9), (4, 10)\}$, then $f$ is a

---

#### In the given function $f$:
- $f(1) = 4$
- $f(2) = 8$
- $f(3) = 9$
- $f(4) = 10$

Every distinct element of domain $A$ has a distinct image in co-domain $B$. Therefore, $f$ is a **one-one function** (injective function).
