## If there are 1024 relations from a set $A = \{1,2,3,4,5\}$ to a set $B$, then the number of elements in $B$ is

---

#### The number of relations from a set $A$ to a set $B$ is $2^{n(A) \times n(B)}$, since a relation is any subset of $A \times B$, and $A \times B$ has $n(A) \times n(B)$ elements, each of which may or may not belong to the subset.

Here $n(A) = 5$, so:
$$2^{5 \times n(B)} = 1024$$

Writing $1024$ as a power of $2$:
$$1024 = 2^{10}$$

So:
$$2^{5 \times n(B)} = 2^{10} \implies 5 \times n(B) = 10 \implies n(B) = 2$$

**Answer: $2$**
