## $A$ என்பது $8$-ஐ விடக் குறைவான இயல் எண்களின் கணம், $B$ என்பது $8$-ஐ விடக் குறைவான பகா எண்களின் கணம் மற்றும் $C$ என்பது இரட்டைப்படை பகா எண்களின் கணம் எனில், கீழ்க்கண்டவற்றை சரிபார்: $(A \cap B) \times C = (A \times C) \cap (B \times C)$

---

#### கொடுக்கப்பட்டவை: $A$ = $8$-ஐ விடக் குறைவான இயல் எண்கள், $B$ = $8$-ஐ விடக் குறைவான பகா எண்கள், $C$ = இரட்டைப்படை பகா எண்கள்.

**படி 1: கணங்களை எழுதுதல்.**
$$A = \{1, 2, 3, 4, 5, 6, 7\}$$
$$B = \{2, 3, 5, 7\}$$

ஒரே இரட்டைப்படை பகா எண் $2$ மட்டுமே, எனவே:
$$C = \{2\}$$

**படி 2: $A \cap B$ ஐக் காணுதல்.**
$B$-ன் ஒவ்வொரு உறுப்பும் $A$-வில் உள்ளது ($B \subseteq A$) என்பதால்:
$$A \cap B = \{2, 3, 5, 7\}$$

**படி 3: $(A \cap B) \times C$ ஐக் காணுதல்.**
$$(A \cap B) \times C = \{2, 3, 5, 7\} \times \{2\} = \{(2,2), (3,2), (5,2), (7,2)\}$$

**படி 4: $A \times C$ ஐக் காணுதல்.**
$$A \times C = \{1,2,3,4,5,6,7\} \times \{2\} = \{(1,2), (2,2), (3,2), (4,2), (5,2), (6,2), (7,2)\}$$

**படி 5: $B \times C$ ஐக் காணுதல்.**
$$B \times C = \{2,3,5,7\} \times \{2\} = \{(2,2), (3,2), (5,2), (7,2)\}$$

**படி 6: $(A \times C) \cap (B \times C)$ ஐக் காணுதல்.**
$$(A \times C) \cap (B \times C) = \{(1,2),(2,2),(3,2),(4,2),(5,2),(6,2),(7,2)\} \cap \{(2,2),(3,2),(5,2),(7,2)\}$$
$$= \{(2,2), (3,2), (5,2), (7,2)\}$$

**படி 7: ஒப்பிடுதல்.**
படி 3-லிருந்து: $(A \cap B) \times C = \{(2,2), (3,2), (5,2), (7,2)\}$.
படி 6-லிருந்து: $(A \times C) \cap (B \times C) = \{(2,2), (3,2), (5,2), (7,2)\}$.

இரு பக்கங்களும் சமமாக இருப்பதால், சரிபார்க்கப்படுகிறது:
$$\mathbf{(A \cap B) \times C = (A \times C) \cap (B \times C) = \{(2,2), (3,2), (5,2), (7,2)\}}$$
