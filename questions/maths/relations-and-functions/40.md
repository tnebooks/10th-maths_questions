## The function $t$ which maps temperature in Celsius ($C$) into temperature in Fahrenheit ($F$) is defined by $t(C) = F$, where $F = \frac{9}{5}C + 32$. Find: (i) $t(0)$ (ii) $t(28)$ (iii) $t(-10)$ (iv) the value of $C$ when $t(C) = 212$ (v) the temperature when the Celsius value is equal to the Fahrenheit value.

---

#### Given: $t(C) = F = \dfrac{9}{5}C + 32$.

**(i) Find $t(0)$.**
$$t(0) = \frac{9}{5}(0) + 32 = 0 + 32 = 32$$

**(ii) Find $t(28)$.**
$$t(28) = \frac{9}{5}(28) + 32 = \frac{252}{5} + 32 = 50.4 + 32 = 82.4$$

**(iii) Find $t(-10)$.**
$$t(-10) = \frac{9}{5}(-10) + 32 = -18 + 32 = 14$$

**(iv) Find $C$ when $t(C) = 212$.**
$$\frac{9}{5}C + 32 = 212$$
$$\frac{9}{5}C = 212 - 32 = 180$$
$$C = 180 \times \frac{5}{9} = 100$$

**(v) Find the temperature when the Celsius value equals the Fahrenheit value.**
Set $C = F$, that is $C = t(C)$:
$$C = \frac{9}{5}C + 32$$
$$C - \frac{9}{5}C = 32$$
$$\frac{5C - 9C}{5} = 32$$
$$\frac{-4C}{5} = 32$$
$$C = 32 \times \left(-\frac{5}{4}\right) = -40$$

So at $-40$ degrees, the Celsius and Fahrenheit readings are equal.

**Answer:**
$$\mathbf{t(0)=32,\ \ t(28)=82.4,\ \ t(-10)=14,\ \ C=100 \text{ when } t(C)=212,\ \ C=F=-40}$$
