## $t$ என்பது சார்பானது செல்சியஸில் ($C$) உள்ள வெப்பநிலையையும், பார்ன்ஹீட்டில் ($F$) உள்ள வெப்பநிலையையும் இணைக்கும் சார்பாகும். மேலும் அது $t(C)=F$ என வரையறுக்கப்பட்டால் (இங்கு $F = \frac{9}{5}C + 32$), (i) $t(0)$ (ii) $t(28)$ (iii) $t(-10)$ (iv) செல்சியஸ் மதிப்பும் பார்ன்ஹீட் மதிப்பும் $212$ ஆக இருக்கும்போது $C$-ன் மதிப்பு (v) செல்சியஸ் மதிப்பும் பார்ன்ஹீட் மதிப்பும் சமமாக இருக்கும்போது வெப்பநிலை ஆகியவற்றைக் காண்க.

---

#### கொடுக்கப்பட்டது: $t(C) = F = \dfrac{9}{5}C + 32$.

**(i) $t(0)$ ஐக் காணுதல்.**
$$t(0) = \frac{9}{5}(0) + 32 = 0 + 32 = 32$$

**(ii) $t(28)$ ஐக் காணுதல்.**
$$t(28) = \frac{9}{5}(28) + 32 = \frac{252}{5} + 32 = 50.4 + 32 = 82.4$$

**(iii) $t(-10)$ ஐக் காணுதல்.**
$$t(-10) = \frac{9}{5}(-10) + 32 = -18 + 32 = 14$$

**(iv) $t(C) = 212$ எனும்போது $C$-ஐக் காணுதல்.**
$$\frac{9}{5}C + 32 = 212$$
$$\frac{9}{5}C = 212 - 32 = 180$$
$$C = 180 \times \frac{5}{9} = 100$$

**(v) செல்சியஸ் மதிப்பும் பார்ன்ஹீட் மதிப்பும் சமமாக இருக்கும்போது வெப்பநிலையைக் காணுதல்.**
$C = F$ எனில், அதாவது $C = t(C)$:
$$C = \frac{9}{5}C + 32$$
$$C - \frac{9}{5}C = 32$$
$$\frac{5C - 9C}{5} = 32$$
$$\frac{-4C}{5} = 32$$
$$C = 32 \times \left(-\frac{5}{4}\right) = -40$$

எனவே $-40$ டிகிரியில், செல்சியஸ் மற்றும் பார்ன்ஹீட் மதிப்புகள் சமமாக இருக்கும்.

**விடை:**
$$\mathbf{t(0)=32,\ \ t(28)=82.4,\ \ t(-10)=14,\ \ t(C)=212 \text{ எனில் } C=100,\ \ C=F=-40}$$
