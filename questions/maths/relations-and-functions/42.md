## The domain of the function $f(x) = \dfrac{1}{3x - 1}$ is

---

#### Given: $f(x) = \dfrac{1}{3x - 1}$.

A rational function is defined for all real numbers except where its denominator becomes zero (since division by zero is undefined). Set the denominator equal to zero to find the excluded value:
$$3x - 1 = 0$$
$$3x = 1$$
$$x = \frac{1}{3}$$

So $f(x)$ is defined for every real number except $x = \dfrac{1}{3}$.

**Answer:**
$$\mathbf{\text{Domain} = \mathbb{R} - \left\{\frac{1}{3}\right\}}$$
