## Forensic scientists calculate the height of a person (in cm) based on their thigh bone length. They generally use the function $h(b) = 2.47b + 54.10$, where $b$ is the length of the thigh bone.
(a) Verify whether $h$ is one-to-one.
(b) If the length of the thigh bone is $50$ cm, find the height of the person.
(c) If the height of a person is $147.96$ cm, find the length of his thigh bone.

---

#### $h(b) = 2.47b + 54.10$ is a linear function of the form $h(b) = mb+c$ with $m = 2.47 \ne 0$. Use this to decide one-to-one-ness, then substitute values for the remaining parts.

**Part (a): Verify whether $h$ is one-to-one**

A function is one-to-one if different inputs always give different outputs, i.e. $h(b_1) = h(b_2) \implies b_1 = b_2$.

Suppose $h(b_1) = h(b_2)$:
$$2.47b_1 + 54.10 = 2.47b_2 + 54.10$$
$$2.47b_1 = 2.47b_2$$
$$b_1 = b_2 \quad (\text{since } 2.47 \ne 0)$$

Since $h(b_1)=h(b_2)$ forces $b_1=b_2$, the function $h$ is **one-to-one**.

**Part (b): Height when $b = 50$ cm**

$$h(50) = 2.47(50) + 54.10 = 123.5 + 54.10 = 177.6$$

The person's height is $\mathbf{177.6}$ cm.

**Part (c): Thigh bone length when $h(b) = 147.96$ cm**

$$147.96 = 2.47b + 54.10$$
$$2.47b = 147.96 - 54.10 = 93.86$$
$$b = \frac{93.86}{2.47} = 38$$

The thigh bone length is $\mathbf{38}$ cm.

**Verification:** Substitute $b=38$ back: $h(38) = 2.47(38)+54.10 = 93.86+54.10 = 147.96$. ✓ Matches the given height exactly.

**Answer:**
(a) $h$ is one-to-one. (b) Height $= 177.6$ cm. (c) Thigh bone length $= 38$ cm.
