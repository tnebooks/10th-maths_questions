## Represent the given relation by (a) an arrow diagram, (b) a graph and (c) a set in roster form:
$$R = \{(x, y) \mid y = x + 3,\ x, y \text{ are natural numbers } < 10\}$$

---

#### Given: $x, y \in \{1, 2, 3, 4, 5, 6, 7, 8, 9\}$ and $y = x + 3$.

Calculate $y$ for each $x$:
- For $x = 1 \implies y = 1 + 3 = 4$
- For $x = 2 \implies y = 2 + 3 = 5$
- For $x = 3 \implies y = 3 + 3 = 6$
- For $x = 4 \implies y = 4 + 3 = 7$
- For $x = 5 \implies y = 5 + 3 = 8$
- For $x = 6 \implies y = 6 + 3 = 9$
- For $x \ge 7 \implies y \ge 10$, which is not less than $10$.

**(a) Arrow Diagram:**
Draw two ovals. In the first oval, write elements of the domain $\{1, 2, 3, 4, 5, 6, 7, 8, 9\}$. In the second oval, write the co-domain $\{1, 2, 3, 4, 5, 6, 7, 8, 9\}$. Draw directed arrows from:
$$1 \to 4, \quad 2 \to 5, \quad 3 \to 6, \quad 4 \to 7, \quad 5 \to 8, \quad 6 \to 9$$

**(b) Graph:**
Plot the points on the Cartesian coordinate plane:
$$(1, 4), \quad (2, 5), \quad (3, 6), \quad (4, 7), \quad (5, 8), \quad (6, 9)$$

**(c) Set in Roster Form:**
$$\mathbf{R = \{(1, 4), (2, 5), (3, 6), (4, 7), (5, 8), (6, 9)\}}$$
