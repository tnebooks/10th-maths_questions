## ஒரு பையில் $5$ சிவப்பு நிறப் பந்துகளும், $6$ வெள்ளை நிறப் பந்துகளும், $7$ பச்சை நிறப் பந்துகளும் மற்றும் $8$ கருப்பு நிறப் பந்துகளும் உள்ளன. சமவாய்ப்பு முறையில் பையிலிருந்து ஒரு பந்து எடுக்கப்படுகிறது. அந்தப் பந்து:
(i) வெள்ளையாக
(ii) கருப்பு அல்லது சிவப்பாக
(iii) வெள்ளையாக இல்லாமல்
(iv) வெள்ளையாகவும், கருப்பாகவும் இல்லாமல்
இருப்பதற்கான நிகழ்தகவுகளைக் காண்க.

---

#### பையிலுள்ள மொத்தப் பந்துகளின் எண்ணிக்கை:
$$n(S) = 5 + 6 + 7 + 8 = 26$$

**(i) எடுக்கப்பட்ட பந்து வெள்ளையாக இருப்பதற்கான நிகழ்தகவு:**
வெள்ளைப் பந்துகளின் எண்ணிக்கை $n(W) = 6$.
$$P(W) = \frac{6}{26} = \frac{3}{13}$$

**(ii) எடுக்கப்பட்ட பந்து கருப்பு அல்லது சிவப்பாக இருப்பதற்கான நிகழ்தகவு:**
கருப்பு அல்லது சிவப்புப் பந்துகளின் எண்ணிக்கை $n(B \cup R) = 8 + 5 = 13$.
$$P(B \cup R) = \frac{13}{26} = \frac{1}{2}$$

**(iii) எடுக்கப்பட்ட பந்து வெள்ளையாக இல்லாமல் இருப்பதற்கான நிகழ்தகவு:**
வெள்ளையல்லாத பந்துகளின் எண்ணிக்கை $= 26 - 6 = 20$.
$$P(W') = 1 - P(W) = 1 - \frac{3}{13} = \frac{10}{13}$$

**(iv) எடுக்கப்பட்ட பந்து வெள்ளையாகவும், கருப்பாகவும் இல்லாமல் இருப்பதற்கான நிகழ்தகவு:**
வெள்ளை மற்றும் கருப்பு அல்லாத பந்துகள் (சிவப்பு + பச்சை) $= 5 + 7 = 12$.
$$P(\text{வெள்ளையுமல்ல, கருப்புமல்ல}) = \frac{12}{26} = \frac{6}{13}$$

**விடை:**
$$\mathbf{\text{(i) } \frac{3}{13}, \quad \text{(ii) } \frac{1}{2}, \quad \text{(iii) } \frac{10}{13}, \quad \text{(iv) } \frac{6}{13}}$$
