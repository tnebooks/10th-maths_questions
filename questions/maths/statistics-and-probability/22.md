## In a class of $50$ students, $28$ opted for NCC, $30$ opted for NSS and $18$ opted for both NCC and NSS. One of the students is selected at random. Find the probability that:
(i) the student opted for NCC but not NSS
(ii) the student opted for NSS but not NCC
(iii) the student opted for exactly one of them

---

#### Total number of students:
$$n(S) = 50$$

Let $A$ be the event of opting for NCC, and $B$ be the event of opting for NSS:
$$n(A) = 28, \quad n(B) = 30, \quad n(A \cap B) = 18$$

**(i) The student opted for NCC but not NSS ($A \cap B'$):**
$$n(A \setminus B) = n(A) - n(A \cap B) = 28 - 18 = 10$$
$$P(A \setminus B) = \frac{10}{50} = \frac{1}{5}$$

**(ii) The student opted for NSS but not NCC ($B \cap A'$):**
$$n(B \setminus A) = n(B) - n(A \cap B) = 30 - 18 = 12$$
$$P(B \setminus A) = \frac{12}{50} = \frac{6}{25}$$

**(iii) The student opted for exactly one of them:**
Number of students opting for exactly one $= n(A \setminus B) + n(B \setminus A) = 10 + 12 = 22$.
$$P(\text{exactly one}) = \frac{22}{50} = \frac{11}{25}$$

**Answer:**
$$\mathbf{\text{(i) } \frac{1}{5}, \quad \text{(ii) } \frac{6}{25}, \quad \text{(iii) } \frac{11}{25}}$$
