## A coin is tossed thrice. Find the probability of getting exactly two heads or at least one tail or two consecutive heads.

---

#### When a coin is tossed three times, the sample space $S$ is:
$$S = \{HHH, HHT, HTH, HTT, THH, THT, TTH, TTT\}$$
Total number of possible outcomes, $n(S) = 8$.

Let the three events be:
- $A$: event of getting exactly two heads
- $B$: event of getting at least one tail
- $C$: event of getting two consecutive heads

**Step 1: Write the outcomes of each event.**
- $A = \{HHT, HTH, THH\} \implies n(A) = 3$
- $B = \{HHT, HTH, HTT, THH, THT, TTH, TTT\} \implies n(B) = 7$ (all outcomes except $HHH$)
- $C = \{HHH, HHT, THH\} \implies n(C) = 3$

**Step 2: Find the intersections of the events.**
- $A \cap B = \{HHT, HTH, THH\} \implies n(A \cap B) = 3$
- $B \cap C = \{HHT, THH\} \implies n(B \cap C) = 2$
- $A \cap C = \{HHT, THH\} \implies n(A \cap C) = 2$
- $A \cap B \cap C = \{HHT, THH\} \implies n(A \cap B \cap C) = 2$

**Step 3: Calculate the union $A \cup B \cup C$.**
Taking the union of all three sets:
$$A \cup B \cup C = \{HHH, HHT, HTH, HTT, THH, THT, TTH, TTT\} = S$$
$$n(A \cup B \cup C) = 8$$

Using the addition theorem of probability for three events:
$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(B \cap C) - P(A \cap C) + P(A \cap B \cap C)$$
$$P(A \cup B \cup C) = \frac{3}{8} + \frac{7}{8} + \frac{3}{8} - \frac{3}{8} - \frac{2}{8} - \frac{2}{8} + \frac{2}{8}$$
$$P(A \cup B \cup C) = \frac{3 + 7 + 3 - 3 - 2 - 2 + 2}{8} = \frac{8}{8} = 1$$

**Answer:**
$$\mathbf{1}$$
