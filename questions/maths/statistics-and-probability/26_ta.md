## ஒரு நாணயம் மூன்று முறை சுண்டப்படுகிறது. சரியாக இரண்டு தலைகள் அல்லது குறைந்தபட்சம் ஒரு பூ அல்லது அடுத்தடுத்து இரண்டு தலைகள் கிடைப்பதற்கான நிகழ்தகவைக் காண்க.

---

#### ஒரு நாணயம் மூன்று முறை சுண்டப்படும்போது, கூறுவெளி $S$:
$$S = \{HHH, HHT, HTH, HTT, THH, THT, TTH, TTT\}$$
கூறுவெளியின் மொத்த உறுப்புகளின் எண்ணிக்கை, $n(S) = 8$.

நிகழ்ச்சிகளைப் பின்வருமாறு கொள்க:
- $A$: சரியாக இரண்டு தலைகள் கிடைப்பது
- $B$: குறைந்தபட்சம் ஒரு பூ கிடைப்பது
- $C$: அடுத்தடுத்து இரண்டு தலைகள் கிடைப்பது

**படி 1: ஒவ்வொரு நிகழ்ச்சியின் உறுப்புகளை எழுத.**
- $A = \{HHT, HTH, THH\} \implies n(A) = 3$
- $B = \{HHT, HTH, HTT, THH, THT, TTH, TTT\} \implies n(B) = 7$ ($HHH$ தவிர மற்ற அனைத்தும்)
- $C = \{HHH, HHT, THH\} \implies n(C) = 3$

**படி 2: வெட்டு நிகழ்ச்சிகளைக் காண.**
- $A \cap B = \{HHT, HTH, THH\} \implies n(A \cap B) = 3$
- $B \cap C = \{HHT, THH\} \implies n(B \cap C) = 2$
- $A \cap C = \{HHT, THH\} \implies n(A \cap C) = 2$
- $A \cap B \cap C = \{HHT, THH\} \implies n(A \cap B \cap C) = 2$

**படி 3: சேர்ப்பு நிகழ்ச்சி $A \cup B \cup C$-ன் நிகழ்தகவு காண.**
மூன்று கணங்களின் சேர்ப்பு:
$$A \cup B \cup C = \{HHH, HHT, HTH, HTT, THH, THT, TTH, TTT\} = S$$
$$n(A \cup B \cup C) = 8$$

நிகழ்தகவின் கூட்டல் தேற்றப்படி:
$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(B \cap C) - P(A \cap C) + P(A \cap B \cap C)$$
$$P(A \cup B \cup C) = \frac{3}{8} + \frac{7}{8} + \frac{3}{8} - \frac{3}{8} - \frac{2}{8} - \frac{2}{8} + \frac{2}{8}$$
$$P(A \cup B \cup C) = \frac{8}{8} = 1$$
