## Prove that $\sqrt{\dfrac{1+\sin\theta}{1-\sin\theta}} + \sqrt{\dfrac{1-\sin\theta}{1+\sin\theta}} = 2\sec\theta$

---

#### Start with the left-hand side and combine the two square-root terms over a common denominator:
$$\text{LHS} = \sqrt{\frac{1+\sin\theta}{1-\sin\theta}} + \sqrt{\frac{1-\sin\theta}{1+\sin\theta}}$$

Write each term with denominator $\sqrt{(1-\sin\theta)(1+\sin\theta)}$:
$$\text{LHS} = \frac{\sqrt{1+\sin\theta}\cdot\sqrt{1+\sin\theta}}{\sqrt{(1-\sin\theta)(1+\sin\theta)}} + \frac{\sqrt{1-\sin\theta}\cdot\sqrt{1-\sin\theta}}{\sqrt{(1+\sin\theta)(1-\sin\theta)}}$$

$$= \frac{(1+\sin\theta) + (1-\sin\theta)}{\sqrt{(1-\sin\theta)(1+\sin\theta)}}$$

Simplify the numerator:
$$(1+\sin\theta) + (1-\sin\theta) = 2$$

So:
$$\text{LHS} = \frac{2}{\sqrt{(1-\sin\theta)(1+\sin\theta)}} = \frac{2}{\sqrt{1-\sin^2\theta}}$$

By the Pythagorean identity $\sin^2\theta + \cos^2\theta = 1$, we have $1 - \sin^2\theta = \cos^2\theta$:
$$\text{LHS} = \frac{2}{\sqrt{\cos^2\theta}} = \frac{2}{|\cos\theta|}$$

Taking $\cos\theta > 0$ (the domain where this identity is considered), $|\cos\theta| = \cos\theta$:
$$\text{LHS} = \frac{2}{\cos\theta}$$

Using $\sec\theta = \dfrac{1}{\cos\theta}$:
$$\text{LHS} = 2\sec\theta = \text{RHS}$$

**Answer:** Hence, $\sqrt{\dfrac{1+\sin\theta}{1-\sin\theta}} + \sqrt{\dfrac{1-\sin\theta}{1+\sin\theta}} = 2\sec\theta$ is proved.
