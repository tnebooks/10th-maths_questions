## If $\sin\theta = \cos\theta$, then the value of $2\tan^2\theta + \sin^2\theta - 1$ is

---

#### $\sin\theta = \cos\theta$ holds when $\theta = 45^\circ$ (in the standard range $0^\circ \le \theta \le 90^\circ$).

At $\theta = 45^\circ$:
$$\sin 45^\circ = \cos 45^\circ = \frac{1}{\sqrt{2}}, \qquad \tan 45^\circ = 1$$

So:
$$\sin^2\theta = \left(\frac{1}{\sqrt{2}}\right)^2 = \frac{1}{2}, \qquad \tan^2\theta = 1^2 = 1$$

Substituting into the expression:
$$2\tan^2\theta + \sin^2\theta - 1 = 2(1) + \frac{1}{2} - 1$$
$$= 2 + 0.5 - 1 = 1.5 = \frac{3}{2}$$

**Alternative check (without assuming $\theta=45^\circ$):** Since $\sin\theta=\cos\theta$, dividing both sides by $\cos\theta$ gives $\tan\theta = 1$, so $\tan^2\theta=1$ regardless. Also $\sin^2\theta+\cos^2\theta=1$ and $\sin\theta=\cos\theta$ gives $2\sin^2\theta=1 \implies \sin^2\theta=\frac{1}{2}$, confirming the same substitution. $\checkmark$

**Answer:**
$$\mathbf{\frac{3}{2}}$$
