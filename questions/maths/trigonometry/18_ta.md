## $\sqrt{\dfrac{1+\sin\theta}{1-\sin\theta}} + \sqrt{\dfrac{1-\sin\theta}{1+\sin\theta}} = 2\sec\theta$ என்ற முற்றொருமையை நிறுவுக

---

#### இடப்புறத்தை (LHS) எடுத்துக் கொண்டு, இரு வர்க்கமூலக் கோவைகளையும் பொது பகுதியின் கீழ் இணைக்க:
$$\text{LHS} = \sqrt{\frac{1+\sin\theta}{1-\sin\theta}} + \sqrt{\frac{1-\sin\theta}{1+\sin\theta}}$$

ஒவ்வொரு உறுப்பையும் $\sqrt{(1-\sin\theta)(1+\sin\theta)}$ என்ற பொது பகுதியுடன் எழுத:
$$\text{LHS} = \frac{\sqrt{1+\sin\theta}\cdot\sqrt{1+\sin\theta}}{\sqrt{(1-\sin\theta)(1+\sin\theta)}} + \frac{\sqrt{1-\sin\theta}\cdot\sqrt{1-\sin\theta}}{\sqrt{(1+\sin\theta)(1-\sin\theta)}}$$

$$= \frac{(1+\sin\theta) + (1-\sin\theta)}{\sqrt{(1-\sin\theta)(1+\sin\theta)}}$$

தொகையை எளிமைப்படுத்த:
$$(1+\sin\theta) + (1-\sin\theta) = 2$$

ஆகவே:
$$\text{LHS} = \frac{2}{\sqrt{(1-\sin\theta)(1+\sin\theta)}} = \frac{2}{\sqrt{1-\sin^2\theta}}$$

பித்தாகரஸ் முற்றொருமை $\sin^2\theta + \cos^2\theta = 1$ -ஐப் பயன்படுத்த, $1 - \sin^2\theta = \cos^2\theta$:
$$\text{LHS} = \frac{2}{\sqrt{\cos^2\theta}} = \frac{2}{|\cos\theta|}$$

இந்த முற்றொருமை பொருந்தும் வட்டத்தில் $\cos\theta > 0$ என்பதால், $|\cos\theta| = \cos\theta$:
$$\text{LHS} = \frac{2}{\cos\theta}$$

$\sec\theta = \dfrac{1}{\cos\theta}$ என்பதைப் பயன்படுத்த:
$$\text{LHS} = 2\sec\theta = \text{RHS}$$

**விடை:** எனவே, $\sqrt{\dfrac{1+\sin\theta}{1-\sin\theta}} + \sqrt{\dfrac{1-\sin\theta}{1+\sin\theta}} = 2\sec\theta$ என்பது நிறுவப்பட்டது.
