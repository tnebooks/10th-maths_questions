## The value of $(1 + \tan\theta + \sec\theta)(1 + \cot\theta - \csc\theta)$ is

---

#### Rewrite every term using $\sin\theta$ and $\cos\theta$: $\tan\theta=\dfrac{\sin\theta}{\cos\theta}$, $\sec\theta=\dfrac{1}{\cos\theta}$, $\cot\theta=\dfrac{\cos\theta}{\sin\theta}$, $\csc\theta=\dfrac{1}{\sin\theta}$.

First factor:
$$1+\tan\theta+\sec\theta = 1+\frac{\sin\theta}{\cos\theta}+\frac{1}{\cos\theta} = \frac{\cos\theta+\sin\theta+1}{\cos\theta}$$

Second factor:
$$1+\cot\theta-\csc\theta = 1+\frac{\cos\theta}{\sin\theta}-\frac{1}{\sin\theta} = \frac{\sin\theta+\cos\theta-1}{\sin\theta}$$

Multiplying the two factors:
$$\frac{(\sin\theta+\cos\theta+1)(\sin\theta+\cos\theta-1)}{\sin\theta\cos\theta}$$

The numerator is a difference of squares with $a=(\sin\theta+\cos\theta)$, $b=1$:
$$(\sin\theta+\cos\theta)^2 - 1^2 = \sin^2\theta+2\sin\theta\cos\theta+\cos^2\theta-1$$

Using $\sin^2\theta+\cos^2\theta=1$:
$$= 1+2\sin\theta\cos\theta-1 = 2\sin\theta\cos\theta$$

So the whole expression becomes:
$$\frac{2\sin\theta\cos\theta}{\sin\theta\cos\theta} = 2$$

**Verification (with $\theta=45^\circ$):** $\tan\theta=1$, $\sec\theta=\sqrt2$, $\cot\theta=1$, $\csc\theta=\sqrt2$. $(1+1+\sqrt2)(1+1-\sqrt2)=(2+\sqrt2)(2-\sqrt2)=4-2=2$. $\checkmark$

**Answer:**
$$\mathbf{2}$$
