## $\sin^2\theta + \dfrac{1}{1+\tan^2\theta}$ -ன் மதிப்பு

---

#### பித்தாகரஸ் முற்றொருமையின்படி, $1+\tan^2\theta = \sec^2\theta$.

எனவே:
$$\frac{1}{1+\tan^2\theta} = \frac{1}{\sec^2\theta} = \cos^2\theta$$

இதனைக் கோவையில் பிரதியிட:
$$\sin^2\theta + \frac{1}{1+\tan^2\theta} = \sin^2\theta + \cos^2\theta$$

பித்தாகரஸ் முற்றொருமை $\sin^2\theta+\cos^2\theta=1$ என்பதால்:
$$\sin^2\theta + \cos^2\theta = 1$$

**சரிபார்ப்பு ($\theta=30^\circ$ எனக் கொண்டு):** $\sin^2 30^\circ = \frac14$, $\tan^2 30^\circ = \frac13$, எனவே $\frac{1}{1+\frac13} = \frac{1}{\frac43} = \frac34$. கூட்டுத்தொகை $= \frac14+\frac34 = 1$. $\checkmark$

**விடை:**
$$\mathbf{1}$$
