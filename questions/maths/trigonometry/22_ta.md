## $\dfrac{\sin(90^\circ - \theta)\sin\theta}{\tan\theta} + \dfrac{\cos(90^\circ - \theta)\cos\theta}{\cot\theta} =$

---

#### நிரப்புக் கோணங்களின் முக்கோணவியல் விகிதங்களைப் பயன்படுத்த:
- $\sin(90^\circ - \theta) = \cos\theta$
- $\cos(90^\circ - \theta) = \sin\theta$

இக்கோவையைப் பிரதியிட:
$$\text{LHS} = \frac{\cos\theta \sin\theta}{\tan\theta} + \frac{\sin\theta \cos\theta}{\cot\theta}$$

$\tan\theta = \frac{\sin\theta}{\cos\theta}$ மற்றும் $\cot\theta = \frac{\cos\theta}{\sin\theta}$ என அறிவோம்:
$$\text{முதல் உறுப்பு} = \frac{\cos\theta \sin\theta}{\frac{\sin\theta}{\cos\theta}} = \cos\theta \sin\theta \times \frac{\cos\theta}{\sin\theta} = \cos^2\theta$$
$$\text{இரண்டாம் உறுப்பு} = \frac{\sin\theta \cos\theta}{\frac{\cos\theta}{\sin\theta}} = \sin\theta \cos\theta \times \frac{\sin\theta}{\cos\theta} = \sin^2\theta$$

இரு உறுப்புகளையும் கூட்ட:
$$\cos^2\theta + \sin^2\theta = 1$$

**விடை:**
$$\mathbf{1}$$
