## $\dfrac{\sin(90^\circ - \theta)\sin\theta}{\tan\theta} + \dfrac{\cos(90^\circ - \theta)\cos\theta}{\cot\theta} =$

---

#### Using the complementary angle formulas:
- $\sin(90^\circ - \theta) = \cos\theta$
- $\cos(90^\circ - \theta) = \sin\theta$

Substitute these into the expression:
$$\text{LHS} = \frac{\cos\theta \sin\theta}{\tan\theta} + \frac{\sin\theta \cos\theta}{\cot\theta}$$

Recall that $\tan\theta = \frac{\sin\theta}{\cos\theta}$ and $\cot\theta = \frac{\cos\theta}{\sin\theta}$:
$$\text{First term} = \frac{\cos\theta \sin\theta}{\frac{\sin\theta}{\cos\theta}} = \cos\theta \sin\theta \times \frac{\cos\theta}{\sin\theta} = \cos^2\theta$$
$$\text{Second term} = \frac{\sin\theta \cos\theta}{\frac{\cos\theta}{\sin\theta}} = \sin\theta \cos\theta \times \frac{\sin\theta}{\cos\theta} = \sin^2\theta$$

Adding the two terms:
$$\cos^2\theta + \sin^2\theta = 1$$

**Answer:**
$$\mathbf{1}$$
